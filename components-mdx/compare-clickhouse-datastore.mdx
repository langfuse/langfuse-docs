[ClickHouse](https://clickhouse.com/) has been [open source since June 15, 2016](https://clickhouse.com/blog/yandex-opensources-click-house) (Apache 2.0). Ten years later it is the most popular open-source analytical database, with [2,000+ contributors](https://clickhouse.com/blog/open-source-10). Langfuse Cloud and self-hosted run the same ClickHouse architecture, so you can move between them without locking into a closed store.

Deprecated. On Langfuse Cloud, organizations created on or after October 22, 2026 can send only `score-create` events to the legacy batch ingestion API. Other event types in the batch are rejected with status `400`, and the response stays `207`. For those organizations, `POST /api/public/traces`, `POST /api/public/events`, and `POST` and `PATCH` `/api/public/spans` and `/api/public/generations` return `404`. Organizations created earlier keep trace, span, and generation writes until <V4CutoverDate />. Legacy reads are not affected by October 22, 2026. On self-hosted Langfuse v4 in `events_only` mode, non-score events are rejected. Migrate to [OpenTelemetry ingestion](/faq/all/deprecated-api-migration#ingestion).

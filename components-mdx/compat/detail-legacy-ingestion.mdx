Deprecated. Trace, span, and generation events via the legacy batch ingestion API are not supported on the v4 data model: on Langfuse Cloud they keep working until <V4CutoverDate />, on self-hosted Langfuse v4 in `events_only` mode they are rejected. The same applies to the older `POST /api/public/traces`, `/spans`, `/generations`, and `/events` endpoints. Migrate to [OpenTelemetry ingestion](/faq/all/deprecated-api-migration#ingestion).

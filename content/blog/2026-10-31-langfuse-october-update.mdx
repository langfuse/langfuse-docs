## Skill management

<Frame>
  ![Skill management](/images/blog/2026-10-31-langfuse-october-update/skill-management.png)
</Frame>

Next to prompts, you can now store and version agent skills in Langfuse. A skill is a `SKILL.md` with task instructions plus optional supporting files. Create skills in the UI, push a local folder, or publish through the API, CLI, MCP, and SDKs. Each version saves the complete set of files, and labels let you promote or roll back a version without changing application code.

With skill tracing configured, generations show which skills have been used. The skill's usage tab combines usage counts, file loads, and linked observations.

→ [Read more](/docs/skill-management/overview)

## Redesigned session view

<Frame>
  ![Redesigned session view](/images/blog/2026-10-31-langfuse-october-update/session-view.png)
</Frame>

The session view now shows user and assistant messages across traces as one continuous conversation. A sidebar navigates messages, traces, and tool usage, so you can follow where an interaction went off track and jump to the trace behind it.

## Scoped API keys and expiration dates

<Frame>
  ![Scoped API keys and expiration dates](/images/blog/2026-10-31-langfuse-october-update/scoped-api-keys.png)
</Frame>

Project API keys now carry permissions: Full access, Viewer, Ingestion, or Scores ingestion. Instrument an application with a key that can send traces but cannot read your prompts or datasets, or collect user feedback from a web app with a key that can only submit scores.

You can also now set an expiration date for your keys. Existing keys keep working as they are.

→ [Read more](/changelog/2026-10-16-project-api-key-permissions)

## More decision models: OpenAI and System One

<Frame>
  ![More decision models: OpenAI and System One](/images/blog/2026-10-31-langfuse-october-update/decision-models.png)
</Frame>

Decision-model evaluators now run on OpenAI's gpt-6-luna through the Decisions API, and on any model that serves TypeSafe's System One API, such as Subquadratic's SubQ Snap or the open-weights Strands Decider you host yourself.

Choice, Score, and Yes/no questions work unchanged, so you can use whichever model fits your cost and latency budget. The Langfuse MCP server also supports decision-model evaluators (API/CLI coming soon).

→ [Read more](/docs/evaluation/evaluation-methods/decision-models)

## Python SDK v5 and JS/TS SDK v6

<Frame>
  ![Python SDK v5 and JS/TS SDK v6](/images/blog/2026-10-31-langfuse-october-update/sdk-majors.png)
</Frame>

Both majors are built for Langfuse v4 and mostly remove APIs that were already deprecated, so for most users the upgrade is a version bump.

New: `experiment_url` / `experimentUrl` links straight to the comparison view, nested metadata becomes filterable dotted paths, span batches are gzip-compressed, and scores are created in batches. If you self-host, both need Langfuse v4.59.0 or later.

→ [Read more](/changelog/2026-10-14-python-sdk-v5-js-sdk-v6)

## Langfuse Government

For government and other highly regulated environments, Langfuse Self-Hosted Government offers a FIPS mode that runs on FIPS 140-3 validated cryptographic modules and hardened images built on Iron Bank's Red Hat UBI 9.

## Fixes & improvements

- Feat: The Experiments page now shows the trade-off between quality, cost, and latency across your runs ([changelog](/changelog/2026-10-19-experiments))
- Feat: Configure LLM connections once at the organization level and share them with every project; a project connection with the same name takes precedence ([changelog](/changelog/2026-10-14-organization-llm-connections))
- Feat: Usage breakdown chart by project or type with CSV export, on the Billing page on Cloud and a new Usage page when self-hosting ([changelog](/changelog/2026-10-06-organization-usage-breakdown))
- Data: Scheduled blob storage exports can include score metadata and provenance, such as the evaluator, annotation queue, and execution trace behind each score ([changelog](/changelog/2026-10-22-blob-storage-score-field-groups))
- Data: Google Cloud Storage as an export target, with a service account key or ADC ([docs](/docs/api-and-data-platform/features/export-to-blob-storage))
- Cost: Prompt cache hit rate shown on traces ([v4.60.0](https://github.com/langfuse/langfuse/releases/tag/v4.60.0))
- UX: Cmd+K jumps to prompts, datasets, annotation queues, and evaluators, and offers create actions and recent picks ([v4.70.0](https://github.com/langfuse/langfuse/releases/tag/v4.70.0))

- Self-hosting: Outbound host allowlists for LLM connections, webhooks, media, and blob storage endpoints ([docs](/self-hosting/configuration/hardening#outbound-url-allowlists))

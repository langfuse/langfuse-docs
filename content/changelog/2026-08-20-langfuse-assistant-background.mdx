The Langfuse Assistant now runs in the background, independently of your browser. Ask it to set up dataset items, fill an annotation queue, or migrate a large dashboard, then keep using Langfuse while it works.

You can start another conversation while the first one is still running, so several tasks can proceed in parallel.

When a run finishes, fails, or needs your approval to continue, you get a notification. You stay in control without having to watch or check back.

For repeating work in one conversation, choose **Always approve** on a tool you are comfortable leaving unattended. The Assistant will then use that tool for the rest of the conversation without asking again, so bigger jobs are not interrupted by the same confirmation over and over again.

Runs also recover more cleanly. Rate limits are retried, tool failures are visible so the Assistant can try again, and a long run that hits a step limit shows a notice instead of looking finished.

As Langfuse's feature development pace increases, we want to give more users access to new features faster.

Organization admins can now enable Feature Previews for everyone from **Organization Settings > Feature Previews**. Current and future members inherit these defaults whenever they use that organization.

For example, test **Compact Session View** and then roll it out to your team. Users can still override this personally if they don't like a preview feature.

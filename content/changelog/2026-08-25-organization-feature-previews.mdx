As Langfuse's feature development pace increases, we want to give more users access to new features faster.

Organization admins can now enable Feature Previews for everyone from **Organization Settings > Feature Previews**. Current and future members inherit these defaults whenever they use that organization.

For example, you can:

- Test **Compact Session View** yourself, then turn it on for your whole team in one step.
- Try a preview with a few teammates first by enabling it for them in **Organization Settings > Members**, before rolling it out to everyone.
- Onboard new teammates with the same experience as the rest of the team, since new members inherit the enabled previews.

Users can still override this personally if they don't like a preview feature.

See the [Feature Previews docs](/docs/administration/feature-previews) for personal settings, per-member controls, and self-hosted setup.

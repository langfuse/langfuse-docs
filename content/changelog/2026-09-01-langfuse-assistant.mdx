Describe what you want and let the [Langfuse Assistant](/docs/langfuse-assistant) take care of it:
- "Create a dataset from the failed generations of last week."
- "Build a dashboard of error rate and p95 latency for the last 7 days."
- "Review this prompt against current best practices and propose a tighter version."

It also works through hundreds or thousands of observations at once. The Assistant fetches them and runs code over them in a sandbox, rather than loading every payload into the model context:

- "Cluster the main error types across the failed observations of the last 7 days."
- "Extract the tool name from every response last week and count how often each one appears."
- "Find what the slowest 100 traces from yesterday have in common."

Every run happens in the background, independently of your browser. Keep exploring Langfuse or start a second conversation while the first one is still working. You get a notification when a run finishes or needs your input.

Anything that changes data or configuration still waits for your approval. For repeating work in one conversation, choose **Always approve** on a tool you are comfortable leaving unattended, and the Assistant uses that tool for the rest of that conversation without asking again.

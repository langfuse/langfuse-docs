The Langfuse Assistant can now get real work done in Langfuse, not only answer questions. Ask it to create a dataset from failed generations, build a dashboard of error rate and latency, or review a prompt against current best practices.

It can also work through hundreds or thousands of observations by fetching them and running code over the results, instead of loading every payload into the model. Find a failure pattern, extract a field, or cluster similar outputs, then keep using Langfuse while it runs.

Those jobs run in the background, independently of your browser. Start another conversation while the first one is still working. You get a notification when a run finishes, fails, or needs your input or approval.

For repeating work in one conversation, choose **Always approve** on a tool you are comfortable leaving unattended. The Assistant then uses that tool for the rest of the conversation without asking again.

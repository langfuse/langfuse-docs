You can now run an evaluator on recent historical observations when you attach it to a rule. Enable **Also run on past observations** to start with scores for existing data while the rule evaluates new observations as they arrive.

Use the backfill to start an online evaluation with scores for observations that arrived before you enabled its rule. For testing an evaluator on selected historical observations or running a one-off evaluation, use [batch evaluation](/docs/evaluation/core-concepts#batch-evaluation).

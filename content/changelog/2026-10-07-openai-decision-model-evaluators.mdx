You can now use OpenAI's `gpt-6-luna` in [decision-model evaluators](/docs/evaluation/evaluation-methods/jev-as-a-judge#use-an-openai-decision-model). Select an existing OpenAI connection, ask choice, score, or yes/no questions, and write one Langfuse score per answer.

OpenAI decision models evaluate the observation input through the OpenAI Decisions API. This makes them useful for high-volume classification, rubric scoring, and binary checks alongside TypeSafe Jev.

You can now run [decision-model evaluators](/docs/evaluation/evaluation-methods/decision-models) on any model that serves TypeSafe's System One API, not only Jev. Add a **TypeSafe (System One)** connection, select the **Custom** upstream, and enter the vendor's base URL and model name. Your Choice, Score, and Yes / no questions work unchanged, for example:

- Route traces by topic or failure mode with a Choice question on a cheaper model.
- Flag out-of-scope requests or PII in outputs with a Yes / no guardrail.
- Grade answer completeness on a Score rubric with an open-weights model you host yourself.

Models you can connect today include [Subquadratic SubQ Snap](https://subq.ai/introducing-subq-snap) (`subq-snap-preview`) and [Strands Decider](https://strandsagents.com/blog/introducing-strands-decider/), an open-weights model you serve with `strands-decider serve`. The docs list the base URL and authentication for each.

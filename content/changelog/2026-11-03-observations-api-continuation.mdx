<ChangelogHeader />

You can now continue expensive Observations API v2 queries across requests when migrating historical data, collecting evaluation inputs, or analyzing chatbot messages. This gives the small percentage of requests that currently time out a way to succeed.

A page may contain fewer observations than `limit`, including none, while `meta.cursor` is present. Keep requesting pages until `meta.cursor` is absent.

For example, with the [Python SDK](/docs/observability/sdk/overview) configured for your project:

```python
from langfuse import get_client

langfuse = get_client()
cursor = None

while True:
    page = langfuse.api.observations.get_many(limit=100, cursor=cursor)
    for observation in page.data:
        print(observation.id)

    cursor = getattr(page.meta, "cursor", None)
    if not cursor:
        break
```

<Callout type="warning">
Some of our documentation examples incorrectly stopped pagination when a page was empty. If you copied one of those examples, update your loop to check `meta.cursor` instead of the number of returned observations. Otherwise, it may stop before retrieving all results.
</Callout>

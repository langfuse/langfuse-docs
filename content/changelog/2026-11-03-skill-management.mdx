## Skill management UI in Langfuse

Next to the prompt management UI, Langfuse now also offers a skill management UI. Teams can centrally store and iterate on skills together. As with all features, skill editing is also supported via API, CLI, MCP and SDKs.

![The refund-policy skill with version history, labels, supporting files, and the Files and Usage tabs.](/images/changelog/2026-11-03-skill-management-editor.png)

## Connect skills with your traces

With [skill tracing configured](/docs/skill-management/tracing), generations show the reported skill list, with links to each version.

![A generation reporting four available skills and a request for refund-policy v1 in the Preview view.](/images/changelog/2026-11-03-skill-management-generation.png)

Traced skill-loading tool calls show which files the agent read. Open **Preview → Skills** on a successful call to see the version and file paths. The skill's **Usage** tab combines usage counts, file loads, and linked observations.

![A loadSkill tool call showing refund-policy v1 and the loaded SKILL.md file in the trace's Preview view.](/images/changelog/2026-11-03-skill-management-tool-load.png)

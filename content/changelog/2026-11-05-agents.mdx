You can now explore the agents in your application from one Langfuse project. Open **Agents** to browse their activity, filter by environment, and inspect an agent's runs, traces, recorded information, and loaded skill versions.

<Callout type="info">
  This internal preview requires Langfuse v4 and the personal `agentsView`
  feature flag. It is not enabled by default.
</Callout>

- **Investigate one agent:** Start with its run count, token usage, or attributed model cost, then open a run and inspect its model and tool observations.
- **Follow a multi-agent workflow:** Open a trace containing a router, researcher, and writer while keeping their identities and usage distinct.
- **Inspect skill usage:** Follow a recorded skill load to its managed version and the observations that loaded its files.

Agent identity comes from your instrumentation: a stable ID identifies the agent and a display name makes it recognizable. Multiple agents can report to the same project. A run is one AGENT invocation; a trace may contain several runs, and sessions can connect related traces.

Usage comes from attributed model calls. Parent AGENT summaries are not added again, and missing usage or pricing stays unknown. [Skill availability and successful loads](/docs/skill-management/tracing#availability-and-loads) remain separate.

## Get started

Read the [Agents guide](/docs/observability/features/agents) to record identities and explore your application when the preview is enabled for your account.

OpenAI and Anthropic connections in the [Langfuse AI Gateway](/docs/gateway/overview) can now send requests to a custom base URL, such as an internal LLM proxy or another endpoint that serves the same API. See [custom base URL](/docs/gateway/features/models#custom-base-url) for setup and allowed hosts.

Self-hosted Langfuse can now run [code evaluators](/docs/evaluation/evaluation-methods/code-evaluators) on an executor you operate. Set `LANGFUSE_CODE_EVAL_DISPATCHER=external` and an endpoint, and Langfuse sends each evaluation over HTTP and stores the returned scores. This lets you run code evaluators on GCP, Azure, or on premises, without AWS Lambda.

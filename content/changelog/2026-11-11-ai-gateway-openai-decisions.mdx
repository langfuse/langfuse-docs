You can now send [OpenAI Decisions](https://developers.openai.com/api/reference/resources/decisions/methods/create) requests through the [Langfuse AI Gateway](/docs/gateway/overview) at `POST /openai/v1/decisions`, using OpenAI or Vercel AI Gateway connections. Each call is traced as a generation, like Responses and Chat Completions calls. See [supported providers](/docs/gateway/features/models#supported-providers) in [Models and providers](/docs/gateway/features/models) and the [REST API endpoints](/docs/gateway/features/rest-api#routes), then [send your first request](/docs/gateway/get-started/first-request).

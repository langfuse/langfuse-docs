You can now send [OpenAI Embeddings](https://developers.openai.com/api/reference/resources/embeddings/methods/create) requests through the [Langfuse AI Gateway](/docs/gateway/overview) at `POST /openai/v1/embeddings`, using OpenAI, OpenRouter, or Vercel AI Gateway connections. Each call is traced as an embedding observation with its token usage and cost, including the cost Vercel AI Gateway bills. See [supported providers](/docs/gateway/features/models#supported-providers) and the [REST API endpoints](/docs/gateway/features/rest-api#routes).

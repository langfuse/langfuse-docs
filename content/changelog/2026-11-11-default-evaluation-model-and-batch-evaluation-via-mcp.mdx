The Langfuse MCP server now lets AI agents manage the project's [default evaluation model](/docs/evaluation/evaluation-methods/llm-as-a-judge#project-default-model) and run [batch evaluations](/docs/evaluation/core-concepts#batch-evaluation) on existing data. For example, an agent can switch the project's default evaluation model to a new judge model, then re-score last week's production observations with the new model.

<ChangelogHeader />

You can now add Microsoft Azure and Google AI Studio connections to the [Langfuse AI Gateway](/docs/gateway/overview), next to OpenAI, Anthropic, Amazon Bedrock, OpenRouter, Vercel AI Gateway, and xAI. An Azure connection calls the deployments of a Microsoft Foundry resource, including Claude deployments through the Anthropic Messages API, and a Google AI Studio connection calls Gemini models with a Gemini API key. See [supported providers](/docs/gateway/features/models#supported-providers) for the API formats of each provider and [Microsoft Azure connections](/docs/gateway/features/models#azure-models) for how deployments become models.

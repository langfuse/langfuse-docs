Audit logs can record who read your data, not only who changed it. With read-access logging on, Langfuse records an access event when a user or API key opens, lists, searches, exports or downloads traces, observations, scores, sessions or experiments. This covers the Langfuse UI and the [public API routes and MCP tools](/docs/administration/audit-logs#read-access-coverage).

Each event records:

- the user or API key and their role;
- the route and request parameters;
- the number of rows returned and the ids of the returned rows;
- whether the read succeeded or was denied;
- the client IP address and user agent.

Access events appear in the audit log viewer and its export, next to change events.

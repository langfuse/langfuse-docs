- **Let Topics find your unknown unknowns.** On Halo, the assistant inside Langfuse, Topics showed some people using it to write homework and Python scripts, and a larger group trying to pen-test it.
- **Give your agents the enrichment layer.** Agents start from the topics via [API, MCP, and CLI](/docs/observability/features/topics#api) and load full traces only where they need them.
- **Go from a topic to a fix.** Filter the tracing table by the topic, read a few of its traces, then fix the prompt or add a new evaluator.

## Four summaries from different view points per trace [#facets]

Topics summarizes each trace from different angles, called **facets**, then clusters every facet summary and names the clusters. There are four built-in facets:

- **Intent:** what the agent was asked to do
- **Sentiment:** how the user felt about the interaction
- **Outcome:** how the trace ended
- **Issues:** the main problem in how the trace was handled

Traces are clustered per facet, so a problem that occurs in multiple Intent topics still shows up as one topic under Issues.

## Live maps and snapshots [#maps-and-snapshots]

A [live map](/docs/observability/features/topics#maps-and-snapshots) groups the traces that match a filter and a sample rate and keeps adding new traces as they arrive, for example one map per agent. A snapshot is a one-time analysis of a time window, for example to put your dataset traces next to production and see which use cases your datasets miss.

## How Topics works [#how-it-works]

After a matching trace stops receiving observations for the configured delay, Topics writes one summary per active facet. It embeds each summary so traces with similar meanings can be grouped within that facet. Live maps rebuild and name these groups daily. Snapshots do this once for the selected time window.

## Get started [#get-started]

Open **Topics** in your project and click **Set up topics**. Topics runs on models from your own [LLM connections](/docs/administration/llm-connection), and the first topics appear about five minutes after setup.

Topics is available on Langfuse Cloud in all regions and on self-hosted Langfuse v4. Each facet summary counts as one [billable unit](/docs/administration/billable-units), and your provider bills the model calls on your own key. Read the [launch post](/blog/introducing-topics) for the full story.

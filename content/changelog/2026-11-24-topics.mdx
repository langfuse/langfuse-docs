- **Let Topics find your unknown unknowns.** On Halo, the assistant inside Langfuse, Topics showed some people using it to write homework and Python scripts, and a larger group trying to pen-test it.
- **Give your agents the enrichment layer.** Agents start from the topics via API, MCP, and CLI and load full traces only where they need them.
- **Go from a topic to a fix.** Filter the tracing table by the topic, read a few of its traces, then fix the prompt or add a new evaluator.

## Four questions you can ask about a trace [#facets]

A **facet** is a question Topics answers about each selected trace. Choose from four built-in facets.

- **Intent:** what the agent was asked to do
- **Sentiment:** how the user felt about the interaction
- **Outcome:** how the trace ended
- **Issues:** the main problem in how the trace was handled

For a travel agent, “Move a flight from Friday to Sunday” might be the Intent **facet summary** for one trace. Topics groups similar summaries into a **topic** such as **Flight changes**. Issues groups traces separately, so you can find a booking failure across several kinds of requests.

## Live maps and snapshots [#maps-and-snapshots]

A [live map](/docs/observability/features/topics#maps-and-snapshots) groups the traces that match a filter and a sample rate and keeps adding new traces as they arrive, for example one map per agent. A snapshot is a one-time analysis of a time window, for example to put your dataset traces next to production and see which use cases your datasets miss.

## How Topics works [#how-it-works]

After a matching trace goes idle, Topics analyzes its selected facets. It turns each summary into an **embedding**, a numeric representation of its meaning, and uses those embeddings to find clusters within each facet. Live maps refresh daily. A snapshot groups traces once for the selected time window.

## Get started [#get-started]

Open **Topics** in your project and click **Set up topics**. Topics runs on models from your own [LLM connections](/docs/administration/llm-connection), and the first topics appear about five minutes after setup.

Topics is available on Langfuse Cloud in all regions and on self-hosted Langfuse v4. On Cloud, each new facet result the model returns and Langfuse stores counts as one [billable unit](/docs/observability/features/topics#models-and-costs), even when the model finds no issue. Your provider bills model calls separately. Read the [launch post](/blog/introducing-topics) for the full story.

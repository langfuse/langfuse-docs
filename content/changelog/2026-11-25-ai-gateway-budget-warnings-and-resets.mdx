You can now configure [email warning thresholds](/docs/gateway/features/budgets#email-alerts) on [Langfuse AI Gateway](/docs/gateway/overview) budgets and [reset spend](/docs/gateway/features/budgets#reset-a-budget) for a user or API key without changing its limit.

- **Warn before requests get blocked:** Enable **85%** and **95%** email alerts alongside the default **100%** alert on any API key, user, default, or organization budget to catch runaway agent loops early.
- **Unblock users and keys immediately:** Select **Reset budget** in a row's menu on **AI Gateway → Budgets** or **Gateway keys** to zero current-period spend while keeping the limit, reset interval, and alert thresholds intact.
- **Self-serve for personal keys:** Admins and owners can reset any user or API key budget, and gateway users can reset budgets on their own API keys.

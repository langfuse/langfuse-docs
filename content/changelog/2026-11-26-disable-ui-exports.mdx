You can now disable all UI-based data exports and downloads for an organization. While disabled, Langfuse blocks batch exports from tables (and downloads in **Project settings** → **Exports**), single trace and session JSON downloads, field downloads, prompt exports, and dashboard CSV downloads. The public API, SDKs, Metrics API, and scheduled blob storage exports are not affected.

**How to disable UI exports**

- Go to **Organization settings** → **General** to disable exports from the UI.
- On self-hosted instances, set `LANGFUSE_DISABLE_UI_EXPORTS=true` on the web container to disable UI exports for every organization and lock the organization toggle.

You can now add [guardrails](/docs/gateway/features/guardrails) to the [Langfuse AI Gateway](/docs/gateway/overview) to block, redact, or log sensitive content in both requests and model responses under **AI Gateway → Guardrails**.

- **Detect PII, secrets, keywords, and custom regex:** Match emails, US SSNs, credit cards, IBANs, IP addresses, API keys, JWTs, private keys, custom secret prefixes, word lists, or custom Rust regexes, with live match previews.
- **Block, redact, or log both directions:** Reject matching traffic with `400`, replace matched text with a label such as `[REDACTED]` before forwarding or returning (and before `FULL` trace capture), or log matches for monitoring.
- **Choose scope and targets:** Run each rule on the latest turn, the entire request history, model responses (including streamed SSE outputs), or both sides, and assign it to everyone or to specific users and API keys.

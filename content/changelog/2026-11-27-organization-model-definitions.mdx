Organization owners and admins can now define models once for every project in **Organization Settings > Models**, instead of duplicating custom definitions per project.

- **Shared pricing across projects:** Define custom or negotiated rates once (or clone a Langfuse default) and every project uses them to [infer cost](/docs/observability/features/token-and-cost-tracking#infer).
- **Clear precedence and overrides:** Matching follows project, then organization, then Langfuse defaults (see [model resolution](/docs/observability/features/token-and-cost-tracking#model-resolution)). Clone an organization model in **Project Settings > Models** to override it for one project.
- **API support:** Sync organization definitions programmatically via the [Organization Models API](https://api.reference.langfuse.com/#tag/organizationmodels). The [project Models API](https://api.reference.langfuse.com/#tag/models) now returns `scope` on every model (deprecating `isLangfuseManaged`).

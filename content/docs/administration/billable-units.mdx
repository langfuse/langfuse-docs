# Billable Units

Langfuse [pricing](/pricing) counts [traces and observations](/docs/observability/data-model#observations-and-traces), [scores](/docs/evaluation/scores/data-model#scores), and [facet results](/docs/observability/features/topics#models-and-costs) in each billing period.

`Units` = `Traces` + `Observations` + `Scores` + `Facet results`

When Topics analyzes a trace, each new facet result the model returns and Langfuse stores adds one unit. The usage breakdown shows these units under **Facet summaries**. For example, a trace analyzed for all four facets adds four Topics units, even if the Issues result says the facet does not apply.

On Langfuse Cloud, use the [pricing calculator](/pricing#pricing-calculator) to estimate your monthly costs. Self-hosted Langfuse (OSS) is free under the MIT license, with no usage-based billing; for self-hosted Enterprise, billable units are one component of the pricing. Unit counts also help you estimate data volume when sizing a self-hosted deployment.

## Monitor usage [#monitor-usage]

The organization usage breakdown shows all four unit types across projects. Use the project dashboard to inspect a single project's counts for a selected date range. Both views are available on Langfuse Cloud and self-hosted deployments.

Start with the organization overview when investigating a usage increase, then open the relevant project's dashboard for more detail. If you already know which project to inspect, go directly to its dashboard.

<Steps>

### Compare usage across projects [#monitor-organization-usage]

In **Organization Settings**, open the page for your deployment. Its **Usage breakdown** chart shows unit counts across all projects in the organization.

| Deployment     | Page        | Required organization role |
| -------------- | ----------- | -------------------------- |
| Langfuse Cloud | **Billing** | Owner                      |
| Self-hosted    | **Usage**   | Owner or Admin             |

<Frame>
  ![Organization usage breakdown showing daily unit counts stacked by project, with By project and By type controls, a date range selector, and CSV download](/images/changelog/2026-10-06-organization-usage-breakdown.png)
</Frame>

- **Select a time range.** Presets span **Past 1 day** through **Past 1 year**, with hourly, daily, weekly, or monthly buckets chosen automatically. All buckets use UTC.
- **Choose a grouping.** Select **By project** to identify projects driving a spike, or **By type** to compare traces, observations, scores, and **Facet summaries**.
- **Export the data.** Use **Download as CSV** for offline analysis or allocating usage across teams. Each row represents a time bucket, project, and unit type.

<Callout type="info">
  Custom date ranges can cover up to one year.
</Callout>

### Inspect usage within a project [#project-usage]

Open a project you have access to, go to **Dashboards**, and select **Langfuse Usage Management**, one of Langfuse's [curated dashboards](/docs/metrics/features/custom-dashboards). This view counts units for that project only.

To estimate monthly usage, select the last 30 days. Add **Total Trace Count**, **Total Observation Count**, and the **Total Score Count** widgets for numeric and categorical scores. If your dashboard shows **Facet results**, add that number too. It shows how many units [Topics analysis](/docs/observability/features/topics#models-and-costs) contributed to this project during the selected period.

If the project uses Topics and the dashboard does not yet show **Facet results**, download the [organization usage breakdown](#monitor-organization-usage) as a CSV for the same period. Filter to the project and sum the `units` column across all four types to get the complete project total.

<Frame>
  ![Langfuse Usage Management dashboard showing total trace, observation, and score counts](/images/docs/self-hosted-usage-management-dashboard.png)
</Frame>

For example, a project with 20,070 traces, 119,500 observations, 561 scores, and 2,000 facet results used **142,131 billable units** in those 30 days.

</Steps>

On Langfuse Cloud, you can also configure [spend alerts](/docs/administration/spend-alerts) to receive email notifications when your organization's bill crosses a monetary threshold.

## FAQ

<FaqDetails>

<Details>
<Summary>How can I track my usage in Langfuse Cloud?</Summary>

Follow the [usage monitoring flow](#monitor-usage) above to start with an organization overview or inspect an individual project.

</Details>

<Details>
<Summary>Do units created by Langfuse features count toward billable units?</Summary>

Yes. Traces, observations, and scores count whether your application sends them or Langfuse features such as LLM-as-a-Judge, Annotation Queues, or experiments create them. Topics usage comes from [analyzing traces for the selected facets](/docs/observability/features/topics#models-and-costs). Reusing the results to refresh a map adds zero units.

</Details>

<Details>
<Summary>When can the same trace produce another Topics unit?</Summary>

Reusing a stored facet result in another map adds zero units. If Topics analyzes the trace again, billing checks the facet and its version. Within a project, the same trace and facet version count once in an hourly billing window, and only if that combination had no billable result in the 24 hours before the window began. A new facet version counts separately.

</Details>

<Details>
<Summary>How can I optimize my Langfuse Cloud usage to reduce cost?</Summary>

If your application scales and you want to optimize Langfuse Cloud cost, please check out [this guide](/faq/all/cutting-costs).

</Details>

</FaqDetails>

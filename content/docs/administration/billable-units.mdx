# Billable Units

Langfuse [pricing](/pricing) is based on the number of ingested units per billing period. Units are either [traces](/docs/observability/data-model#observations-and-traces), [observations](/docs/observability/data-model#observations-and-traces) or [scores](/docs/evaluation/scores/data-model#scores).

`Units` = `Count of Traces` + `Count of Observations` + `Count of Scores`

On Langfuse Cloud, use the [pricing calculator](/pricing?calculatorOpen=true) to estimate your monthly costs. Self-hosted Langfuse (OSS) is free under the MIT license, with no usage-based billing; for self-hosted Enterprise, billable units are one component of the pricing. Unit counts also help you estimate data volume when sizing a self-hosted deployment.

## Monitor usage [#monitor-usage]

You can monitor the same unit types at two levels: across your organization to see which projects drive usage, and within a project to inspect its trace, observation, and score counts. Both views are available on Langfuse Cloud and self-hosted deployments.

Start with the organization overview when investigating a usage increase, then open the relevant project's dashboard for more detail. If you already know which project to inspect, go directly to its dashboard.

<Steps>

### Compare usage across projects [#monitor-organization-usage]

In **Organization Settings**, open the page for your deployment. Its **Usage breakdown** chart shows unit counts across all projects in the organization.

| Deployment     | Page        | Required organization role |
| -------------- | ----------- | -------------------------- |
| Langfuse Cloud | **Billing** | Owner                      |
| Self-hosted    | **Usage**   | Owner or Admin             |

<Frame>
  ![Organization usage breakdown showing daily unit counts stacked by project, with By project and By type controls, a date range selector, and CSV download](/images/changelog/2026-10-06-organization-usage-breakdown.png)
</Frame>

- **Select a time range.** Presets span **Past 1 day** through **Past 1 year**, with hourly, daily, weekly, or monthly buckets chosen automatically. All buckets use UTC.
- **Choose a grouping.** Select **By project** to identify projects driving a spike, or **By type** to compare traces, observations, and scores.
- **Export the data.** Use **Download as CSV** for offline analysis or allocating usage across teams. Each row represents a time bucket, project, and unit type.

<Callout type="info">
  Custom date ranges can cover up to one year.
</Callout>

### Inspect usage within a project [#project-usage]

Open a project you have access to, go to **Dashboards**, and select **Langfuse Usage Management**, one of Langfuse's [curated dashboards](/docs/metrics/features/custom-dashboards). This view counts units for that project only.

Select the same date range as the organization chart to inspect the period that caught your attention. To estimate a month of usage for this project, select the last 30 days and add **Total Trace Count**, **Total Observation Count**, and **Total Score Count** (including both numeric and categorical score widgets).

<Frame>
  ![Langfuse Usage Management dashboard showing total trace, observation, and score counts](/images/docs/self-hosted-usage-management-dashboard.png)
</Frame>

For the example above:

`Units` = `20,070 Traces` + `119,500 Observations` + `561 Scores` = `140,131 units / month` (≈ `1,681,572 units / year`)

</Steps>

On Langfuse Cloud, you can also configure [spend alerts](/docs/administration/spend-alerts) to receive email notifications when your organization's bill crosses a monetary threshold.

## FAQ

<FaqDetails>

<Details>
<Summary>How can I track my usage in Langfuse Cloud?</Summary>

Follow the [usage monitoring flow](#monitor-usage) above to start with an organization overview or inspect an individual project.

</Details>

<Details>
<Summary>Do units created by Langfuse features count toward billable units?</Summary>

Yes. Any trace, observation, or score stored in Langfuse counts as a billable unit, whether it is sent by your application or created by Langfuse features such as LLM-as-a-Judge, Annotation Queues, or experiments.

</Details>

<Details>
<Summary>How can I optimize my Langfuse Cloud usage to reduce cost?</Summary>

If your application scales and you want to optimize Langfuse Cloud cost, please check out [this guide](/faq/all/cutting-costs).

</Details>

</FaqDetails>

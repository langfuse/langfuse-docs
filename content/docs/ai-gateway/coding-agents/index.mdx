# Coding agents

<AiGatewayBetaCallout />

Point your coding agent at the AI Gateway to record every model call of every session in Langfuse: prompts, tool definitions, tool calls and results, reasoning, tokens, cost, and latency. No plugin or hook is required. You only change the agent's base URL and API key.

Before you start, create a gateway key as in [Send your first request](/docs/ai-gateway/get-started/first-request).

- [Claude Desktop and Claude Code](/docs/ai-gateway/coding-agents/claude-code) (Anthropic route)
- [Codex](/docs/ai-gateway/coding-agents/codex) (OpenAI route)
- [OpenCode](/docs/ai-gateway/coding-agents/opencode) (Anthropic and OpenAI routes)
- [pi](/docs/ai-gateway/coding-agents/pi) (Anthropic and OpenAI routes)
- [GitHub Copilot CLI and app](/docs/ai-gateway/coding-agents/github-copilot) (CLI: Anthropic and OpenAI routes; app: OpenAI route)

To add tags, an environment, or other context to agent traces, send [request headers](/docs/ai-gateway/features/tracing#request-headers), or add [metadata to the gateway key](/docs/ai-gateway/features/api-keys#key-metadata) so that every call made with it carries the same context.

## Trace shape [#trace-shape]

The gateway groups calls into Langfuse sessions by the agent's own session ID. A **turn** is one user prompt plus every model call the agent makes until it stops. Without turn grouping, each model call is its own trace, so a prompt with four tool steps shows up as four traces. Use the **Sessions** view to follow a conversation.

| Agent          | Session ID                            | Traces                                                                                                                    |
| -------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Claude Code    | `claude-code:<session uuid>`          | One per model call, or one per turn with [opt-in turn grouping](/docs/ai-gateway/coding-agents/claude-code#turn-grouping) |
| Codex          | `codex:<thread id>`                   | **One per turn**, built in                                                                                                |
| OpenCode       | `opencode:<ses_…>`                    | One per model call, or one per turn with an [experimental plugin](/docs/ai-gateway/coding-agents/opencode#turn-grouping)  |
| pi             | `pi:<session id>`                     | One per model call, or one per turn with an [experimental extension](/docs/ai-gateway/coding-agents/pi#turn-grouping)     |
| GitHub Copilot | none (app: set `langfuse-session-id`) | One per model call                                                                                                        |

- Traces are named after the agent (`claude-code`, `codex`, …), except for GitHub Copilot. Generations are named after the API format (`anthropic.messages`, `openai.responses`).
- Resuming or continuing (`--resume`, `-c`, `codex resume`, `--session-id`) keeps the same session.
- Original agent IDs are kept in metadata under `agent.*`. See [inferred agent context](/docs/ai-gateway/features/tracing#inferred-agent-context).

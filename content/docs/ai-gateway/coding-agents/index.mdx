# Coding agents

<AiGatewayBetaCallout />

Point your coding agent at the AI Gateway to record every model call of every session in Langfuse: prompts, tool definitions, tool calls and results, reasoning, tokens, cost, and latency. No plugin or hook is required. You only change the agent's base URL and API key.

Before you start, create a gateway key as in [Send your first request](/docs/ai-gateway/get-started/first-request) and export `LANGFUSE_GATEWAY_HOST` and `LANGFUSE_GATEWAY_KEY`. For Codex, store the key in [`~/.codex/.env`](/docs/ai-gateway/coding-agents/codex#store-the-key) instead.

- [Claude Desktop and Claude Code](/docs/ai-gateway/coding-agents/claude-code) (Anthropic route)
- [Codex](/docs/ai-gateway/coding-agents/codex) (OpenAI route)
- [OpenCode](/docs/ai-gateway/coding-agents/opencode) (Anthropic and OpenAI routes)
- [pi](/docs/ai-gateway/coding-agents/pi) (Anthropic and OpenAI routes)
- [GitHub Copilot CLI and app](/docs/ai-gateway/coding-agents/github-copilot) (CLI: Anthropic and OpenAI routes; app: OpenAI route)

To add tags, an environment, or other context to agent traces, see [request headers](/docs/ai-gateway/features/request-headers).

## Trace shape [#trace-shape]

| Agent          | Session                               | Default trace grouping                            | Turn grouping                                                                                | Trace name    | Generation name                           |
| -------------- | ------------------------------------- | ------------------------------------------------- | -------------------------------------------------------------------------------------------- | ------------- | ----------------------------------------- |
| Claude Code    | `claude-code:<session uuid>`          | one trace per model call                          | [opt-in](/docs/ai-gateway/coding-agents/claude-code#turn-grouping) (beta telemetry env vars) | `claude-code` | `anthropic.messages`                      |
| Codex          | `codex:<thread id>`                   | **one trace per turn** (all tool rounds together) | built in                                                                                     | `codex`       | `openai.responses`                        |
| OpenCode       | `opencode:<ses_…>`                    | one trace per model call                          | [experimental plugin](/docs/ai-gateway/coding-agents/opencode#turn-grouping)                 | `opencode`    | `anthropic.messages` / `openai.responses` |
| pi             | `pi:<session id>`                     | one trace per model call                          | [experimental extension](/docs/ai-gateway/coding-agents/pi#turn-grouping)                    | `pi`          | `anthropic.messages` / `openai.responses` |
| GitHub Copilot | none (app: set `langfuse-session-id`) | one trace per model call                          | not available                                                                                | none          | `anthropic.messages` / `openai.responses` |

- A **turn** is one user prompt plus every model call the agent makes until it stops. Without turn grouping, a prompt with four tool steps shows up as four traces in the same session. **Use the Sessions view** to follow a conversation.
- Resuming or continuing (`--resume`, `-c`, `codex resume`, `--session-id`) keeps the same session.
- Original agent IDs are kept in metadata under `agent.*`. See [inferred agent context](/docs/ai-gateway/features/request-headers#inferred-agent-context).

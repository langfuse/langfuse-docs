# AI Gateway

<AiGatewayBetaCallout />

<PlatformOverviewDiagram highlightGateway />

AI is being used in many different areas of a company, with engineers using coding agents, often dozens of AI apps running in production, internally or externally. Companies need to keep visibility and control over rising AI usage, answering questions like **"Who uses which models, for what, and what does it cost?"**

The Langfuse AI Gateway is a central chokepoint to govern all AI traffic, easy to host, adopt, and enforce. It can log all requests natively in Langfuse to analyze and make decisions based on AI usage.

## What the Langfuse AI Gateway can do

Most gateways tell you what AI costs. Because every call through the Langfuse AI Gateway becomes a full Langfuse trace, it's more powerful than that.

- See your spend. Cost and usage for every call land in one [AI spend dashboard](/docs/ai-gateway/features/analytics), by model and provider.
- Know who spends it. Every [key](/docs/ai-gateway/features/api-keys) belongs to a person or service and can carry a team or cost center, so AI spend breaks down the way your company is organized.
- Understand what it's spent on. Each call can be logged as a [complete trace](/docs/ai-gateway/features/tracing). You can see what an application or a team actually did with a model, and use the same search, evaluations, and annotation you already use in Langfuse. Or simply ask [Halo](/docs/api-and-data-platform/features/halo): "What does this team use Claude Code for?"
- Control model usage. [Approve models](/docs/ai-gateway/features/models) centrally, so expensive or unvetted ones don't creep in unnoticed.
- Incrementally adopt deeper tracing. Enforce logging every model call by mandating the gateway, and allow teams to incrementally add more detail (for example, tool call executions of complex agents) to AI traces in Langfuse via [OpenTelemetry](/integrations/native/opentelemetry) or one of our 50+ [integrations](/integrations). OpenTelemetry distributed tracing merges these traces within Langfuse.
- Use Langfuse as memory for agents. All data in Langfuse is available via [MCP](/docs/api-and-data-platform/features/mcp-server) and the [CLI](/docs/api-and-data-platform/features/cli), so you can give agents access to search all AI requests they made in the past, which is the foundation for self-improvement loops.
- Export metrics and raw logs to a [data lake](/docs/api-and-data-platform/features/export-to-blob-storage). This enables any custom downstream process in finance and data teams.

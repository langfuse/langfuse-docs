# OpenAI SDK

<AiGatewayBetaCallout />

Use the official [OpenAI SDKs](https://developers.openai.com/api/docs/libraries) for Python and TypeScript with the gateway by changing the base URL and the API key. Requests need an `OPENAI` provider credential in your organization.

Before you start, create a gateway key and export `LANGFUSE_GATEWAY_HOST` and `LANGFUSE_GATEWAY_KEY` as in [Send your first request](/docs/ai-gateway/get-started/first-request). Replace `<model-id>` with an ID from the [models endpoint](/docs/ai-gateway/sdks-and-apis/rest-api#list-models).

## Configure the client [#configure-the-client]

Set the base URL to the gateway's OpenAI route, `/openai/v1`, and pass the gateway key as the API key. The SDK sends it as `Authorization: Bearer`.

<LangTabs items={["Python", "TypeScript"]}>
<Tab>

```bash
pip install openai
```

```python
import os

from openai import OpenAI

client = OpenAI(
    base_url=os.environ["LANGFUSE_GATEWAY_HOST"] + "/openai/v1",
    api_key=os.environ["LANGFUSE_GATEWAY_KEY"],
)
```

</Tab>
<Tab>

```bash
npm install openai
```

```ts
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: `${process.env.LANGFUSE_GATEWAY_HOST}/openai/v1`,
  apiKey: process.env.LANGFUSE_GATEWAY_KEY,
});
```

</Tab>
</LangTabs>

## Chat Completions [#chat-completions]

<LangTabs items={["Python", "TypeScript"]}>
<Tab>

```python
completion = client.chat.completions.create(
    model="<model-id>",
    messages=[{"role": "user", "content": "Say hello"}],
)
print(completion.choices[0].message.content)
```

</Tab>
<Tab>

```ts
const completion = await client.chat.completions.create({
  model: "<model-id>",
  messages: [{ role: "user", content: "Say hello" }],
});
console.log(completion.choices[0].message.content);
```

</Tab>
</LangTabs>

<Callout type="warning">
  Streamed Chat Completions end with a usage chunk whose `choices` array is
  empty, even if you didn't ask for usage. Skip chunks without choices. See
  [streaming usage](/docs/ai-gateway/sdks-and-apis/rest-api#streaming-usage).
</Callout>

## Add request headers [#request-headers]

Set [request headers](/docs/ai-gateway/features/tracing#request-headers) on the client for every call, or per call for values such as a session ID.

<LangTabs items={["Python", "TypeScript"]}>
<Tab>

```python
client = OpenAI(
    base_url=os.environ["LANGFUSE_GATEWAY_HOST"] + "/openai/v1",
    api_key=os.environ["LANGFUSE_GATEWAY_KEY"],
    default_headers={"langfuse-tags": "checkout,production"},
)

response = client.responses.create(
    model="<model-id>",
    input="Say hello",
    extra_headers={"langfuse-session-id": "<session-id>"},
)
```

</Tab>
<Tab>

```ts
const client = new OpenAI({
  baseURL: `${process.env.LANGFUSE_GATEWAY_HOST}/openai/v1`,
  apiKey: process.env.LANGFUSE_GATEWAY_KEY,
  defaultHeaders: { "langfuse-tags": "checkout,production" },
});

const response = await client.responses.create(
  { model: "<model-id>", input: "Say hello" },
  { headers: { "langfuse-session-id": "<session-id>" } },
);
```

</Tab>
</LangTabs>

<Callout type="info">
  The gateway already records every call. Don't also trace the same client with
  the [Langfuse OpenAI integration](/integrations/model-providers/openai-py), or
  each call is recorded twice.
</Callout>

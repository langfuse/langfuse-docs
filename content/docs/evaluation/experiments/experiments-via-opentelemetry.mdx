# Experiments via OpenTelemetry

This page is part of [Agent evals](/docs/evaluation).

Attach experiment metadata to [OpenTelemetry](/integrations/native/opentelemetry) spans so Langfuse groups those traces as an experiment run.

<Callout type="info">
  **Using Python or TypeScript?** Use [Experiments via SDK](/docs/evaluation/experiments/experiments-via-sdk).
  The Langfuse SDKs set these attributes automatically.
</Callout>

See the [Experiments data model](/docs/evaluation/experiments/data-model) for how datasets, experiment runs, items, traces, and scores relate.

## Ingest experiment spans [#ingest-experiment-spans]

Set experiment and item attributes on your OTEL spans so Langfuse can synthesize them as one experiment. The attribute list, baggage propagation pattern, and per-item loop live in the OpenTelemetry integration docs:

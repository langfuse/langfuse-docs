## Online evaluation

Score live production traces as they arrive. Create an evaluator, test it on representative observations, and attach a rule that selects which incoming observations to score.

[Get started with online evaluation →](/docs/evaluation/get-started/online)

## Offline evaluation

Run repeatable experiments on a dataset before you ship. Compare prompts or application changes, score each result, and inspect which test cases improved or regressed.

[Get started with offline evaluation →](/docs/evaluation/get-started/offline)

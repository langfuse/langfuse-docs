# Agent evals and experiments

Agent evals are a repeatable check of application behavior. You replace guesswork with [scores](/docs/evaluation/scores/overview) — numeric, categorical, boolean, or text — on live traces and on dataset experiments, so you can catch regressions before you ship.

This page is for teams that need to measure quality in production and compare prompt, model, or code changes before release. If you want to score traffic today, start with [Evaluate Production Traffic](/docs/evaluation/get-started/online). To test a change on a fixed set of cases, start with [Evaluate with Datasets](/docs/evaluation/get-started/offline).

Evaluation runs across most of the [AI engineering loop](/academy/ai-engineering-loop): you score live traces, turn interesting examples into datasets, run experiments, and judge the results with manual or automated evaluators. It happens both **online**, on live production traces, and **offline**, before you ship a change.

## What you can do with evals

Teams use Langfuse evals to:

- Score live production traces with [LLM-as-a-Judge](/docs/evaluation/evaluation-methods/llm-as-a-judge) or [code evaluators](/docs/evaluation/evaluation-methods/code-evaluators)
- Review edge cases in [annotation queues](/docs/evaluation/evaluation-methods/annotation-queues) and collect [user feedback](/docs/observability/features/user-feedback)
- Compare prompt, model, or code changes with [experiments](/docs/evaluation/experiments/experiments-via-ui) on a [dataset](/docs/evaluation/experiments/datasets)
- Block a deploy when an experiment regresses in [CI](/docs/evaluation/experiments/experiments-ci-cd)

## Getting started

You can evaluate both:

- [live incoming traces](/docs/evaluation/get-started/online) to measure quality on production data and track trends over time.
- [results from running tests on a pre-defined dataset](/docs/evaluation/get-started/offline), to make sure your changes are ready for production.

For how evaluators, scores, datasets, and experiments fit together, read [Core Concepts](/docs/evaluation/core-concepts).

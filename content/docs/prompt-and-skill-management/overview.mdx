# Prompt and Skill Management

Use Langfuse to version prompt templates and agent skills. Assign labels such as `staging` and `production` to select the versions your application receives.

## Prompts [#prompts]

Use **Prompt Management** for text and chat templates with variables and model configuration. Fetch and compile a template for a model call, cache it in the SDK, or test it in the Playground.

[Explore Prompt Management](/docs/prompt-management/overview) or [create your first prompt](/docs/prompt-management/get-started).

## Skills [#skills]

Use **Skill Management** for a `SKILL.md` file and its reference documents and scripts. Langfuse versions the files together; your agent decides when to load them.

Skill Management is in beta. [Explore Skill Management](/docs/skill-management/overview) or [create and load your first skill](/docs/skill-management/get-started).

## Use prompts and skills together [#choosing-what-to-manage]

For example, a support agent can fetch a chat prompt for the conversation and load the refund skill when a customer asks for a refund.

[Link prompts to generations](/docs/prompt-management/features/link-to-traces) and [trace skill availability and loads](/docs/skill-management/tracing) to inspect the instructions used during a run.

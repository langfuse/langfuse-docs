# Prompt and Skill Management

Langfuse versions prompt templates and agent skills. Choose based on what your application needs to load:

| Manage                                           | Use for                                                                         | Get started                                            |
| ------------------------------------------------ | ------------------------------------------------------------------------------- | ------------------------------------------------------ |
| [Prompts](/docs/prompt-management/overview)      | Text or chat templates your application compiles for model calls                | [Create a prompt](/docs/prompt-management/get-started) |
| [Skills](/docs/skill-management/overview) (beta) | Task instructions in `SKILL.md` and supporting files your agent loads as needed | [Create a skill](/docs/skill-management/get-started)   |

Both support version labels such as `staging` and `production`. An agent can use a prompt for its conversation and load a skill for a specific task, such as handling a refund.

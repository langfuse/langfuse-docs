## 🚧 In progress and coming next [#roadmap]

### New capabilities

- **Langfuse Gateway**
  - Provide a thin, bring-your-own-key gateway with virtual keys and access controls across Langfuse Cloud and self-hosted deployments.
  - Connect requests directly to Langfuse tracing and cost tracking, with clear visibility into model usage and spend.
- **Proactive issue detection**
  - Help teams find the problems that matter without manually reviewing every trace.
  - Group interactions into recurring topics, behaviors, and failure modes, and surface the most important issues with useful summaries and examples.
- **Agent transcripts**
  - A chat view that makes long-running agents easier to read
  - Standardized data model exposed across API, MCP, evals, and other features
- **In-app agent improvements**
  - Solve for complex workflows like "LLM-as-a-judge calibration" end-to-end with extended sandbox capabilities
- **Multi-span/trajectory evals**
- **Security/auth improvements**
  - Custom and standardized RBAC model across user-roles and api-based access
  - User-owned and service-account API keys
  - OAuth for the MCP server with user-level permissions
  - Support for Groups synced from IDPs for easier access management
- **Org-level dashboards**
  - Aggregated overview of cost, quality and other metrics across all projects of an organization
- **Vibe-codeable/custom trace viewers**

### Self-hosting improvements

- Increase batching of S3 events in ingest to reduce cost
- Move to Rust for the ingestion pipeline to reduce latency and cost
- Hardened Langfuse Government

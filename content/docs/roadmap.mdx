## 🚧 In progress and coming next [#roadmap]

### New capabilities

- **Langfuse Gateway**
  - Provide a thin, bring-your-own-key gateway with virtual keys and access controls across Langfuse Cloud and self-hosted deployments.
  - Connect requests directly to Langfuse tracing and cost tracking, with clear visibility into model usage and spend.
- **Proactive issue detection**
  - Develop Topics to identify recurring user intents, behaviors, and failure patterns across traces at scale.
  - Surface clusters, outliers, and representative examples so teams can find issues without reviewing every trace.
- **Agent transcripts**
  - Extend a shared transcript representation across traces and sessions to make long-running agent interactions easier to read.
  - Use transcripts as a foundation for Topics and other improvement workflows.
- **In-app agent improvements**
  - Help users complete workflows such as LLM-as-a-judge calibration with more capable sandbox tools.
- **Multi-span, session, and trajectory evaluations**
  - Evaluate complete agent interactions using the observations-first data model.
- **Skill management**
  - Manage and version agent skills, then trace how agents use them.
- **Security and authentication improvements**
  - Add granular permissions to API keys, including gateway-specific access.
  - Support user-owned and service-account API keys.
  - Add OAuth authentication to the MCP server so it can respect user-level permissions.
- **Organization-level dashboards**
  - Provide an aggregated view of cost, quality, and other metrics across an organization's projects.
- **Usage visibility and cost controls**
  - Break down Langfuse usage by project, environment, and span name for organization admins.
  - Control ingestion with filters, sampling, and usage limits.
- **Custom trace viewers**
  - Build and adapt trace viewers with coding agents.

### Self-hosting improvements

- Batch more S3 ingestion events to reduce cost.
- Move ingestion work to Rust in stages to reduce latency and cost.
- Extend [Hardening for Government](/self-hosting/configuration/hardening#hardening-for-government) with FIPS-compatible deployment support and hardened images.

# Why don't I see Gateway pages like Models, Keys, and Analytics?

Under **Organization settings → AI Gateway**, the gateway has a **Setup** tab and the **Models**, **Gateway keys**, and **Analytics** tabs. If those tabs are disabled or empty, check the following.

## Is a project set? [#no-project]

The gateway records every call in one project of your organization. Until an admin chooses that project, the **Models**, **Gateway keys**, and **Analytics** tabs stay disabled.

To fix this, go to **Organization settings → AI Gateway → Setup** and choose a project. See [Set up Gateway as an admin](/docs/gateway/get-started/admin-setup#configure-the-gateway).

## Does your role include Analytics? [#analytics-role]

Owners, admins, and people with the AI Gateway role see the **Analytics** tab. People with the AI Gateway role only see their own usage. See [Analytics](/docs/gateway/features/analytics).

## Are you self-hosting with the `NONE` ingestion mode? [#none-mode]

On self-hosted Langfuse, the `NONE` ingestion mode routes requests without recording them. You don't need a project in this mode, but **Analytics** shows "Gateway requests are not recorded" instead of charts, because there is no data to chart.

To see analytics, switch to the `USAGE` or `FULL` [ingestion mode](/docs/gateway/features/tracing#ingestion-modes) and choose a project.

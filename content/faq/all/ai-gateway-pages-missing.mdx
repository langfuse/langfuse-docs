# Why can't I open AI Gateway pages like Providers & Models or Gateway keys?

The **AI Gateway** sidebar has the **Overview**, **Providers & Models**, **Gateway keys**, and **Tracing** pages. If a page is disabled, missing, or empty, check the following.

## Is the gateway set up? [#no-project]

The gateway records every call in one project of your organization. Until an admin finishes the setup wizard on **Overview** and chooses that project, **Providers & Models** and **Gateway keys** stay disabled for admins, and other members see "AI Gateway isn’t set up yet".

To fix this, go to **AI Gateway → Overview** and complete the setup. See [Set up Gateway as an admin](/docs/gateway/get-started/admin-setup#configure-the-gateway).

## Does your role include analytics? [#analytics-role]

Owners, admins, and people with the AI Gateway role see the analytics on **Overview**. People with the AI Gateway role only see their own usage. See [Analytics](/docs/gateway/features/analytics).

The **Tracing** link opens the gateway's project. It appears for owners and admins after setup, if they can open that project.

## Are you self-hosting with the `NONE` ingestion mode? [#none-mode]

On self-hosted Langfuse, the `NONE` ingestion mode routes requests without recording them. You don't need a project in this mode, but **Overview** shows "Gateway requests are not recorded" instead of charts, because there is no data to chart.

To see analytics, switch to the `USAGE` or `FULL` [ingestion mode](/docs/gateway/features/tracing#ingestion-modes) and choose a project.

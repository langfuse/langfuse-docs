# How is gateway usage billed?

The gateway does not resell tokens. Your model provider bills model usage to your own provider account.

Each generation the gateway records counts as a [billable unit](/docs/administration/billable-units), like any other observation. What is recorded depends on the organization's [ingestion mode](/docs/gateway/features/tracing#ingestion-modes):

- The default `USAGE` mode records one generation per request (usage, cost, and metadata, without prompts or responses). That generation is billable on Langfuse Cloud.
- `FULL` also records one generation per request, including prompts and responses. That generation is billable on Langfuse Cloud.
- `NONE` records nothing, so it creates no Langfuse billable units.

<Callout type="info">
  `NONE` is available only on
  [self-hosted](/self-hosting/configuration/ai-gateway) Langfuse. Langfuse Cloud
  always records `USAGE` or `FULL`, so every Cloud gateway request produces a
  billable generation. There is no unbilled pass-through mode on Cloud.
</Callout>

Self-hosted Langfuse (OSS) has no usage-based billing. For self-hosted Enterprise, [billable units](/docs/administration/billable-units) are one component of the pricing.

# Can I add dataset items to an annotation queue?

No. [Annotation queue](/docs/evaluation/evaluation-methods/annotation-queues) items can reference only **traces**, **observations**, or **sessions**. Dataset items cannot be added to a queue directly.

To review outputs produced for a dataset, run an [experiment](/docs/evaluation/experiments/datasets) on it. Each experiment item is stored as a trace with observations, so you can select the experiment's observations in the observations table and use **Add to Annotation Queue**, or add them through the [annotation queue API](/docs/evaluation/evaluation-methods/annotation-queues).

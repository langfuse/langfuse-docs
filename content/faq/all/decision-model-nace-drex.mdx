# How do I use Nace Drex decision models?

Nace serves its [Drex models](https://console.nace.ai/docs/drex/reference/models) through the System One API. Add a connection with the adapter **typesafe**, choose the **Nace (Drex)** upstream, and paste a **Nace API key**. Then select that connection in a [decision-model evaluator](/docs/evaluation/evaluation-methods/decision-models). Like the [TypeSafe Jev](/faq/all/decision-model-typesafe-jev) upstreams, it needs no base URL or extra headers (the preset uses `https://console.nace.ai/v1`). The JSON state and backtick field references work the same way as for Jev.

The connection offers `drex-max` and `drex-v2.0` as default models. Langfuse prices both models by input tokens only, since output tokens are not billed: `drex-max` at $0.03 and `drex-v2.0` at $0.06 per 1M input tokens. See [Nace pricing](https://console.nace.ai/docs/drex/reference/pricing).

<Callout type="info">
  Nace does not serve `jev-latest`, so pick a Drex model for evaluators that use
  a Nace connection.
</Callout>

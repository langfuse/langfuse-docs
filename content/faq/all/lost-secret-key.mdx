# I lost my Langfuse secret key. Can I retrieve it?

No. The secret key (`sk-lf-...`) is shown only once, when the key is created. Langfuse stores only a one-way hash of it, so neither the UI nor Langfuse support can show it again. The settings page shows the public key and a masked preview of the secret.

To replace a lost key:

1. Go to **Project Settings → API Keys** and click **Create new API keys**.
2. Update your application with the new public and secret key.
3. Delete the old key. Deleting a key invalidates it immediately.

There is no separate "rotate" action; creating a new key and deleting the old one is how you rotate keys. Managing project API keys requires the `Owner` or `Admin` role on the project. See [API keys](/docs/administration/rbac#api-keys).

# Can I manage agent skills with Langfuse Prompt Management?

Langfuse now has native **[Skill Management](/docs/skill-management/overview)** in beta. It versions a `SKILL.md` file and its supporting text resources together, lets you select versions through labels, and connects skill availability and loads to your agent traces. See [getting started](/docs/skill-management/get-started) for beta access and setup.

## Which feature should I use? [#which-feature]

Use [Prompt Management](/docs/prompt-management/overview) for text or chat templates you compile for a model call. Use [Skill Management](/docs/skill-management/overview) for agent workflows made up of instructions and supporting files. You can use both in the same agent.

## What about skills I already store as prompts? [#existing-prompts]

Your prompt-based workflow can continue to use prompt versioning, labels, and [prompt-to-trace links](/docs/prompt-management/features/link-to-traces). If you want to manage files together as a skill, export the content into a folder with a root `SKILL.md` and [publish it as a skill](/docs/skill-management/version-control).

Add the required `name` and `description` frontmatter, preserve relative links to supporting files, and update your agent to [load the skill](/docs/skill-management/load-skills). Skill version numbers and labels belong to the new skill; they do not inherit your prompt's version history. [Skill tracing](/docs/skill-management/tracing) records the skill catalog and successful loads in your instrumented agent.

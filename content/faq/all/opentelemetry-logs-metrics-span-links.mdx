# Does Langfuse support OpenTelemetry logs, metrics, or span links?

Langfuse ingests **traces only**, at `/api/public/otel/v1/traces` over OTLP/HTTP with protobuf or JSON payloads. gRPC is not supported.

| Signal                             | Supported                                                                                               |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Traces (spans, attributes, events) | Yes                                                                                                     |
| Metrics                            | No. `/api/public/otel/v1/metrics` accepts requests so exporters do not fail, but the data is discarded. |
| Logs                               | No. There is no logs endpoint.                                                                          |
| Span links                         | No. Links on spans are ignored during ingestion and are not shown in the UI.                            |

Any language with an OpenTelemetry SDK, for example Java, Go, or .NET, can send traces to Langfuse with an OTLP/HTTP exporter. To show token usage, cost, and model information, set the attributes described in [OpenTelemetry](/integrations/native/opentelemetry). Langfuse calculates metrics such as cost and latency from the ingested traces; see [Metrics](/docs/metrics/overview).

# Why does `from langfuse.decorators import langfuse_context` fail?

The `langfuse.decorators` module and the `langfuse_context` object were part of the Python SDK v2. They were removed in **v3.0.0**, so the import fails on v3 and later. Import `observe` from `langfuse` and use the client returned by `get_client()` instead:

```python
from langfuse import observe, get_client, propagate_attributes

langfuse = get_client()
```

| Python SDK v2 (`langfuse_context`)                                                           | Current Python SDK                                                                |
| -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `from langfuse.decorators import observe`                                                    | `from langfuse import observe`                                                    |
| `langfuse_context.update_current_observation(...)`                                           | `langfuse.update_current_span(...)` or `langfuse.update_current_generation(...)`  |
| `langfuse_context.update_current_trace(user_id=..., session_id=..., tags=..., metadata=...)` | `with propagate_attributes(user_id=..., session_id=..., tags=..., metadata=...):` |
| `langfuse_context.update_current_trace(public=True)`                                         | `langfuse.set_current_trace_as_public()`                                          |
| `langfuse_context.get_current_trace_id()`                                                    | `langfuse.get_current_trace_id()`                                                 |
| `langfuse_context.score_current_trace(...)`                                                  | `langfuse.score_current_trace(...)`                                               |
| `langfuse_context.flush()`                                                                   | `langfuse.flush()`                                                                |

<Callout type="info">
  `langfuse.update_current_trace()` existed in the v3 SDK but was removed in v4. Its correlating attributes moved to `propagate_attributes()`. Trace input and output now come from the root observation: set them with `span.update(input=..., output=...)` on the root span.
</Callout>

For step-by-step guides, see the upgrade paths [v2 → v3](/docs/observability/sdk/upgrade-path/python-v2-to-v3), [v3 → v4](/docs/observability/sdk/upgrade-path/python-v3-to-v4), and [v4 → v5](/docs/observability/sdk/upgrade-path/python-v4-to-v5).

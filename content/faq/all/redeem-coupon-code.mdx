# How do I redeem a startup, research, or YC coupon code?

Coupon codes from the [startup program](/startups), the [research program](/research), and the Y Combinator deal add credits to a paid Langfuse Cloud organization. An organization `Owner` redeems the code:

1. Upgrade the organization to a paid plan in **Organization Settings → Billing**. Credits only apply to a paid subscription.
2. Open **Organization Settings** and replace `settings` at the end of the URL with `coupon`. The URL now ends in `/organization/<organization-id>/coupon`.
3. Enter the coupon code and select **Redeem coupon**.

We email you once the code has been reviewed, and the credits then apply to your invoices.

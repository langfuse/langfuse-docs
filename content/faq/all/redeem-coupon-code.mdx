# How do I redeem a startup, research, or YC coupon code?

Coupon codes from the [startup program](/startups), the [research program](/research), and the Y Combinator deal add credits to a paid Langfuse Cloud organization. An organization `Owner` redeems the code:

1. Upgrade the organization to the Core plan in **Organization Settings → Billing** and pay the US$29 base fee. This activates the billing account that receives the credits. You can move to a higher plan once the credits are applied.
2. Open **Organization Settings** and replace `settings` at the end of the URL with `coupon`. The URL now ends in `/organization/<organization-id>/coupon`.
3. Enter the coupon code and select **Redeem coupon**.

We email you once the code has been reviewed, and the credits then apply to your invoices.

<Callout type="warning">
  We cannot refund the initial US$29 Core plan payment that activates the billing account.
</Callout>

<Callout type="info">
  Subscriptions created before November 23, 2026 are billed through Stripe. Redeem the code through Stripe instead: select **Add Promotion Code** in **Organization Settings → Billing**.
</Callout>

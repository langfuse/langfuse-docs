# How much CPU, memory, and disk does self-hosted Langfuse need?

For a single-VM [Docker Compose](/self-hosting/deployment/docker-compose) deployment, use at least 4 CPU cores and 16 GiB of memory (for example an AWS `t3.xlarge`) and around 100 GiB of disk.

For deployments with separate services, the minimum per component is:

| Service                   | Minimum                                                            |
| ------------------------- | ------------------------------------------------------------------ |
| Langfuse web container    | 2 CPU, 4 GiB memory                                                |
| Langfuse worker container | 2 CPU, 4 GiB memory                                                |
| PostgreSQL                | 2 CPU, 4 GiB memory                                                |
| Redis/Valkey              | 1 CPU, 1.5 GiB memory                                              |
| ClickHouse                | 2 CPU, 8 GiB memory                                                |
| Blob storage              | S3-compatible service, or SeaweedFS/MinIO with 2 CPU, 4 GiB memory |

Disk usage depends mostly on your ingestion volume and retention, and most of it is in ClickHouse and blob storage. Scale workers horizontally based on CPU, and scale ClickHouse vertically. See [Scaling](/self-hosting/configuration/scaling) and [Reduce ClickHouse disk size](/faq/all/reduce-clickhouse-disk-size).

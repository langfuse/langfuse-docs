# How do I get token usage and cost per user or per LLM call via the API?

## Per user (aggregated)

Query the [Metrics API v2](/docs/metrics/features/metrics-api) with the `observations` view and the `userId` dimension. `userId` is a [high-cardinality dimension](/docs/metrics/features/metrics-api#high-cardinality-dimensions), so the query must set `config.row_limit`, order by a metric in `desc` order, and must not set a `timeDimension`.

```python
import json
import os

import requests

query = {
    "view": "observations",
    "dimensions": [{"field": "userId"}],
    "metrics": [
        {"measure": "totalCost", "aggregation": "sum"},
        {"measure": "totalTokens", "aggregation": "sum"},
    ],
    "filters": [],
    "fromTimestamp": "2026-10-01T00:00:00Z",
    "toTimestamp": "2026-11-01T00:00:00Z",
    "orderBy": [{"field": "sum_totalCost", "direction": "desc"}],
    "config": {"row_limit": 100},
}

response = requests.get(
    "https://cloud.langfuse.com/api/public/v2/metrics",
    params={"query": json.dumps(query)},
    auth=(os.environ["LANGFUSE_PUBLIC_KEY"], os.environ["LANGFUSE_SECRET_KEY"]),
)
for row in response.json()["data"]:
    print(row["userId"], row["sum_totalCost"], row["sum_totalTokens"])
```

Other measures include `inputTokens`, `outputTokens`, `inputCost`, and `outputCost`. To get only one user, add a filter on `userId` instead of grouping by it.

## Per LLM call

Use the [Observations API v2](/docs/api-and-data-platform/features/public-api#v2) and request the `usage` and `model` field groups:

```bash
curl -u "$LANGFUSE_PUBLIC_KEY:$LANGFUSE_SECRET_KEY" \
  "https://cloud.langfuse.com/api/public/v2/observations?type=GENERATION&userId=<userId>&fields=core,basic,usage,model&fromStartTime=2026-10-01T00:00:00Z&toStartTime=2026-11-01T00:00:00Z"
```

Each observation includes `usageDetails`, `costDetails`, and `totalCost`. For how Langfuse calculates cost, see [Token and cost tracking](/faq/all/costs-tokens-langfuse).

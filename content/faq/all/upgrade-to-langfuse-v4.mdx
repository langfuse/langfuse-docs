# Upgrade to Langfuse v4

Langfuse v4 uses an observations-first data model. The [v4 overview](/docs/v4) explains what changed. New managed projects already use v4 and need no migration.

For existing projects, complete the applicable steps below.

## 1. Upgrade trace ingestion [#ingestion]

Python v2 and JS/TS v3 (and older) depend on legacy ingestion, which stops after the v4 cutover. Python v3 and JS/TS v4 are deprecated and can show data with up to a 10-minute delay.

| Current setup                          | Action                                                                                                                                                                                               |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Langfuse Python SDK below 4.7.0        | Upgrade to Python SDK 4.7.0 or later. Follow the [SDK upgrade paths](/docs/observability/sdk/upgrade-path) for each major-version change.                                                            |
| Langfuse JS/TS SDK below 5.4.0         | Upgrade to JS/TS SDK 5.4.0 or later. Follow the [SDK upgrade paths](/docs/observability/sdk/upgrade-path) for each major-version change.                                                             |
| Custom REST ingestion or OpenTelemetry | Follow the [custom ingestion v4 guide](/integrations/native/opentelemetry/migration-to-v4). It covers OTLP/HTTP, real-time ingestion, attribute propagation, root input/output, and immutable spans. |

## 2. Migrate the v3 features you use [#features]

Skip any row that does not apply to your project.

| If you use                                                       | Action before the v4 cutover                                                                                                                                                                                                                                                                                           |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Deprecated SDK resources or REST endpoints                       | Use the [endpoint migration guide](/faq/all/deprecated-api-migration) to move to Observations API v2, Metrics API v2, Scores API v3, or the Experiments APIs. Deprecated reads return `404` after cutover.                                                                                                             |
| Trace-level or legacy-dataset LLM-as-a-Judge evaluators          | [Migrate to observation-level evaluators](/faq/all/llm-as-a-judge-migration). Legacy evaluators stop producing scores after cutover.                                                                                                                                                                                   |
| Blob storage, PostHog, or Mixpanel with the legacy export source | Migrate to enriched observations using the [blob storage](/docs/api-and-data-platform/features/export-to-blob-storage#upgrade-path), [PostHog](/integrations/analytics/posthog#migrate-export-source), or [Mixpanel](/integrations/analytics/mixpanel#migrate-export-source) guide. Legacy exports stop after cutover. |

## 3. Complete the rollout [#rollout]

### Managed projects [#managed]

If your organization still shows the **Preview** toggle, enable it. Then open the [in-app migration checklist](https://cloud.langfuse.com/project/~/v4) and resolve every required action.

The managed cutover date has not been announced. Follow the [v4 timeline](/docs/v4#timeline) for updates.

### Self-hosted deployments [#self-hosted]

Self-hosted v4 is currently a release candidate. Use the [v3 to v4 upgrade guide](/self-hosting/upgrade/upgrade-guides/upgrade-v3-to-v4) to test the migration in staging, but wait for a stable v4 release before migrating production.

There is no forced cutover date. Langfuse v3 receives security patches through January 2027. The [self-hosted compatibility matrix](/self-hosting/upgrade/versioning#sdk-server) lists supported SDKs and APIs.

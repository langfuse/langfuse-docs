# Observability for eve with Langfuse

This guide shows you how to integrate **Langfuse** with **eve** to trace and debug your agents.

> **What is eve?** [eve](https://eve.dev) is an open-source TypeScript framework from Vercel for building durable agents as ordinary files in a project. It ships with durable execution, a sandbox, tools, subagents, schedules, and built-in OpenTelemetry tracing.

> **What is Langfuse?** [Langfuse](https://langfuse.com) is an open-source observability platform for AI agents and LLM applications. It helps you visualize and monitor model calls, tool usage, cost, latency, and more. Use [Langfuse Cloud](/cloud) (hosted by Langfuse, free tier, no infrastructure to run) or [self-host](/self-hosting) it.

eve emits OpenTelemetry spans that follow the [OpenTelemetry GenAI semantic conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/). Registering the `LangfuseSpanProcessor` as an eve OpenTelemetry destination sends every agent turn, model call, and tool call to Langfuse.

## Get Started

<Steps>

### Create an eve agent

If you don't have an eve agent yet, scaffold one with the eve CLI:

```bash
npx eve@latest init my-agent
cd my-agent
```

See the full [eve quickstart](https://eve.dev/docs/getting-started) for details.

### Install the Langfuse span processor

```bash
npm install @langfuse/otel
```

### Add your Langfuse credentials

Get your API keys from your [Langfuse project settings](https://cloud.langfuse.com) and add them to your agent's `.env` file. You can sign up for [Langfuse Cloud](https://langfuse.com/cloud) or [self-host Langfuse](https://langfuse.com/self-hosting).

```bash filename=".env"
LANGFUSE_PUBLIC_KEY="pk-lf-..."
LANGFUSE_SECRET_KEY="sk-lf-..."
LANGFUSE_BASE_URL="https://cloud.langfuse.com" # 🇪🇺 EU region
# LANGFUSE_BASE_URL="https://us.cloud.langfuse.com" # 🇺🇸 US region
```

### Add Langfuse as an OpenTelemetry destination

eve loads one file per tracing destination from `agent/instrumentation/`. Create `agent/instrumentation/langfuse.ts`:

```typescript filename="agent/instrumentation/langfuse.ts"
import { LangfuseSpanProcessor } from "@langfuse/otel";
import { otelIntegration } from "eve/instrumentation/otel";

export default otelIntegration({
  spanProcessors: [
    new LangfuseSpanProcessor({
      environment: process.env.VERCEL_ENV ?? "development",
    }),
  ],
});
```

The `LangfuseSpanProcessor` reads `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY`, and `LANGFUSE_BASE_URL` from the environment. Its default export filter keeps eve's agent, model, and tool spans and drops eve's durable-workflow orchestration spans.

<Callout type="info">
  Outside development, eve includes prompts and completions only for
  conversations with a `public` audience. Other turns still arrive in Langfuse
  with timing, token usage, and cost, but without inputs and outputs. To capture
  content in preview or production, set a `tracePolicy` in
  `agent/instrumentation/otel.ts`, as described in eve's [OpenTelemetry
  docs](https://eve.dev/docs/observability/otel).
</Callout>

### Define a simple agent

A minimal eve agent is a tool plus a system prompt. The weather agent below, with a single `getWeather` tool and a short instruction, is enough to produce a trace with model calls and a tool call:

```ts filename="agent/tools/getWeather.ts"
import { defineTool } from "eve/tools";
import { z } from "zod";

export default defineTool({
  description: "Return mock weather data for a city.",
  inputSchema: z.object({ city: z.string().min(1) }),
  async execute({ city }) {
    return { city, condition: "cloudy", temperatureC: 18 };
  },
});
```

```ts filename="agent/agent.ts"
import { defineAgent } from "eve";

export default defineAgent({
  model: "openai/gpt-5.4-mini",
});
```

```markdown filename="agent/instructions.md"
You are a concise weather assistant. When asked about the weather, call the
getWeather tool, then answer in one sentence. Mention that the data is mocked.
```

eve discovers these files automatically. Model provider authentication (the Vercel AI Gateway or an `OPENAI_API_KEY`) follows the [eve quickstart](https://eve.dev/docs/getting-started).

### Run your agent

Start your agent and send it a message, for example _"What's the weather in Berlin?"_:

```bash
npm run dev
```

Each agent turn is now exported to Langfuse.

### View traces in Langfuse

Open your [Langfuse dashboard](https://cloud.langfuse.com) to see a trace for each agent turn. eve's spans map to the Langfuse data model as follows:

- The **agent turn** (`invoke_agent`) becomes the root **agent observation**, with the user message as input and the final answer as output.
- **Model calls** (`chat`) become **generations** with the model name, token usage, and cost.
- **Tool calls** (`execute_tool`) become **tool observations** with their arguments and results.
- The **eve session** becomes a Langfuse [session](/docs/observability/features/sessions), so all turns of a conversation are grouped together.

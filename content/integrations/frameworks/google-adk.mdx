# Trace Google ADK agents with Langfuse

Langfuse shows each Google ADK agent run, model call and tool call as spans in one trace, and maps the user ID and session ID of the runner to Langfuse users and sessions. Two lines in Python send the traces, `GoogleADKInstrumentor().instrument()` and `get_client()`, and your agent code stays the same.

> **What is Google ADK?** The [Agent Development Kit](https://adk.dev/) (ADK) is Google's open source framework for building agents and multi-agent workflows. A `Runner` executes an agent with `run_async` inside a session.

> **What is Langfuse?** [Langfuse](/) is an open source LLM engineering platform for tracing, evaluating and debugging AI agents. Use [Langfuse Cloud](/cloud) or [self-host](/self-hosting) it.

> **How do they work together?** The OpenInference instrumentor for ADK wraps ADK calls and emits an OpenTelemetry span for each invocation, agent run, model call and tool call. The Langfuse client exports those spans to Langfuse.

<Callout type="info">
  Requires Python 3.11 or later (Langfuse Python SDK 5); ADK alone needs 3.10. The code on this page ran with `langfuse` 5.2.0, `google-adk` 2.15 and `openinference-instrumentation-google-adk` 1.1.9, as of November 2026.

</Callout>

## Send traces to Langfuse [#setup]

Install ADK, the Langfuse SDK and the OpenInference instrumentor, a third-party package maintained by Arize:

```bash
pip install langfuse "google-adk>=2" openinference-instrumentation-google-adk
```

Add your [Langfuse API keys](/docs/observability/sdk/overview#client-setup) and your [Gemini API key](https://aistudio.google.com/app/apikey) to the environment:

```bash filename=".env"
LANGFUSE_SECRET_KEY="sk-lf-..."
LANGFUSE_PUBLIC_KEY="pk-lf-..."
LANGFUSE_BASE_URL="https://cloud.langfuse.com" # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com
GOOGLE_API_KEY="..."
```

Call the instrumentor before the first run. `auth_check()` stops the script with `UnauthorizedError` if Langfuse rejects the keys or the host.

```python filename="agent.py"
import asyncio

from google.adk.agents import Agent
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService
from google.genai import types
from langfuse import get_client, propagate_attributes
from openinference.instrumentation.google_adk import GoogleADKInstrumentor

# Send every ADK agent, model and tool span to Langfuse. Call this before the first run.
GoogleADKInstrumentor().instrument()

langfuse = get_client()
assert langfuse.auth_check(), "Langfuse rejected the keys or the host"

def get_weather(city: str) -> dict:
    """Return the weather for a city."""
    return {"city": city, "forecast": "sunny"}

agent = Agent(
    name="weather_agent",
    model="gemini-3.5-flash",
    instruction="Answer weather questions with the get_weather tool.",
    tools=[get_weather],
)

async def main():
    session_service = InMemorySessionService()
    await session_service.create_session(app_name="weather_app", user_id="user-123", session_id="session-abc")
    runner = Runner(agent=agent, app_name="weather_app", session_service=session_service)
    message = types.Content(role="user", parts=[types.Part(text="What is the weather in Tokyo?")])

    with propagate_attributes(trace_name="weather-agent-request", tags=["google-adk"]):
        async for event in runner.run_async(user_id="user-123", session_id="session-abc", new_message=message):
            if event.is_final_response() and event.content and event.content.parts:
                print(event.content.parts[0].text)

asyncio.run(main())
langfuse.flush()  # a short script exits before the background export runs
```

## Agent runs, tool calls and model calls in one trace [#trace]

Each `run_async` call becomes one trace. With instrumentor 1.1.9 the script above produces these spans:

- `invocation [weather_app]`: the run, with the user message and the final response
- `agent_run [weather_agent]`: the agent
- `call_llm`: each Gemini call, with the prompt, the response and the token use
- `execute_tool get_weather`: the tool call, with its arguments and result

The user ID and session ID passed to the runner become the Langfuse [user](/docs/observability/features/users) and [session](/docs/observability/features/sessions), so you can filter traces by user and follow a conversation across runs. Span names depend on the instrumentor version.

## Trace names and tags [#names-tags]

`propagate_attributes` sets the trace name and tags on every span of the run inside its block. Use the trace name to tell agents apart in the trace list, and tags to filter by feature or environment.

## Multi-agent workflows [#workflows]

An ADK [`Workflow`](https://adk.dev/workflows/) runs several agents as a graph, and each node appears as its own span with its own model calls, token use and cost. The notebook has a [researcher and writer pipeline](/guides/cookbook/integration_google_adk#example-3-multi-agent-pipeline-with-workflow).

## User feedback as scores [#scores]

To attach a thumbs-up or an evaluation result to a run, create the trace ID upfront, run the agent inside a Langfuse span with that ID, and pass the same ID to `create_score`. See the [notebook example](/guides/cookbook/integration_google_adk#example-4-score-traces-with-user-feedback) and [Scores](/docs/evaluation/scores/overview).

## Troubleshooting [#troubleshooting]

If no trace appears:

- Check that `langfuse.auth_check()` passes and that the keys belong to the region in `LANGFUSE_BASE_URL`.
- Call `GoogleADKInstrumentor().instrument()` before the first run.
- Call `langfuse.flush()` before a short script exits.

The Gemini free tier has low rate limits. If a run fails with a rate-limit error, wait and rerun, or use a lighter model. See [Missing traces](/faq/all/missing-traces) for more causes.

## FAQ [#faq]

**How do I trace a Google ADK agent?** Call `GoogleADKInstrumentor().instrument()` and `get_client()` before the first run.

**Does Langfuse show ADK tool calls?** Yes. Each tool call appears as an `execute_tool` span inside the agent run.

**How are users and sessions tracked?** The user ID and session ID passed to the runner become the Langfuse user and session.

**Can I trace multi-agent workflows?** Yes. Each node of an ADK `Workflow` appears as its own span.

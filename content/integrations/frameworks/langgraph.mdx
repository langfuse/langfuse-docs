# Trace LangGraph without LangSmith, using Langfuse

Langfuse traces a LangGraph agent without LangSmith: one callback handler in the call config records every node, model call and tool call. LangGraph sends traces to LangSmith only when LangSmith tracing is switched on with an environment variable, and the Langfuse handler works with that variable unset.

> **What is LangGraph?** [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) is LangChain's open source framework for building stateful agents as graphs of nodes. LangChain's `create_agent` builds a LangGraph agent with a model node and a tools node.

> **What is Langfuse?** [Langfuse](/) is an open source LLM engineering platform for tracing, evaluating and debugging AI agents. Use [Langfuse Cloud](/cloud) or [self-host](/self-hosting) it.

> **How do they work together?** LangGraph runs on LangChain's callback system. The [Langfuse LangChain integration](/integrations/frameworks/langchain) provides a `CallbackHandler`, `langfuse.langchain` in Python and `@langfuse/langchain` in TypeScript, that turns each callback into a span in Langfuse.

<Callout type="info">
  Requires Python 3.11 or later (Langfuse Python SDK 5), or Node.js 22 or later (Langfuse TypeScript SDK 6).

</Callout>

Add your [Langfuse API keys](/docs/observability/sdk/overview#client-setup) and your OpenAI key to the environment. Any LangChain chat model works; OpenAI is the example.

```bash filename=".env"
LANGFUSE_SECRET_KEY="sk-lf-..."
LANGFUSE_PUBLIC_KEY="pk-lf-..."
LANGFUSE_BASE_URL="https://cloud.langfuse.com" # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com
OPENAI_API_KEY="sk-proj-..."
```

## Trace LangGraph in Python [#python]

The code ran with `langfuse` 5.2.0, `langchain` 1.5.2, `langgraph` 1.2.24 and `langchain-openai` 1.8.5, with no LangSmith variable set, as of November 2026.

```bash
pip install langfuse langchain langgraph langchain-openai
```

`auth_check()` stops the script with `UnauthorizedError` if Langfuse rejects the keys or the host.

```python filename="agent.py"
from langchain.agents import create_agent
from langchain_core.messages import HumanMessage
from langchain_core.tools import tool
from langchain_openai import ChatOpenAI
from langfuse import get_client, propagate_attributes
from langfuse.langchain import CallbackHandler

langfuse = get_client()
assert langfuse.auth_check(), "Langfuse rejected the keys or the host"
langfuse_handler = CallbackHandler()

@tool
def get_weather(city: str) -> str:
    """Get the weather for a city."""
    return f"The weather in {city} is sunny."

agent = create_agent(
    ChatOpenAI(model="gpt-4.1-mini"),
    tools=[get_weather],
    system_prompt="Answer weather questions with the get_weather tool.",
)

with propagate_attributes(trace_name="weather-agent", user_id="user-123", session_id="session-abc", tags=["langgraph"]):
    result = agent.invoke(
        {"messages": [HumanMessage(content="What is the weather in Tokyo?")]},
        config={"callbacks": [langfuse_handler]},  # the only Langfuse line in the call
    )

print(result["messages"][-1].content)
langfuse.flush()  # a short script exits before the background export runs
```

## Trace LangGraph in TypeScript [#typescript]

The code ran with `@langfuse/langchain` 6.1.1, `langchain` 1.6.8, `@langchain/langgraph` 1.7.5 and `@langchain/openai` 1.8.5 on Node.js 22, as of November 2026. `@langfuse/langchain` 6 needs `@langchain/core` 1 or later.

```bash
npm install langchain @langchain/openai @langchain/langgraph @langfuse/langchain @langfuse/otel @langfuse/tracing zod "@opentelemetry/sdk-node@>=0.202.0 <0.300.0"
```

Start OpenTelemetry with the Langfuse span processor once, and shut it down before a short script exits:

```ts filename="agent.ts"
import { createAgent, tool } from "langchain";
import { ChatOpenAI } from "@langchain/openai";
import { HumanMessage } from "@langchain/core/messages";
import { NodeSDK } from "@opentelemetry/sdk-node";
import { LangfuseSpanProcessor } from "@langfuse/otel";
import { CallbackHandler } from "@langfuse/langchain";
import * as z from "zod";

// Start OpenTelemetry with the Langfuse span processor once, before the first call.
const sdk = new NodeSDK({ spanProcessors: [new LangfuseSpanProcessor()] });
sdk.start();

const getWeather = tool(({ city }) => `The weather in ${city} is sunny.`, {
  name: "get_weather",
  description: "Get the weather for a city",
  schema: z.object({ city: z.string() }),
});

const agent = createAgent({
  model: new ChatOpenAI({ model: "gpt-4.1-mini" }),
  tools: [getWeather],
  systemPrompt: "Answer weather questions with the get_weather tool.",
});

const langfuseHandler = new CallbackHandler({
  sessionId: "session-abc",
  userId: "user-123",
  tags: ["langgraph"],
});

const result = await agent.invoke(
  { messages: [new HumanMessage("What is the weather in Tokyo?")] },
  { callbacks: [langfuseHandler] }, // the only Langfuse line in the call
);

console.log(result.messages.at(-1)?.content);
await sdk.shutdown(); // a short script exits before the background export runs
```

## Nodes, model calls and tool calls in one trace [#trace]

Each `invoke` becomes one trace. The Python script above produces these spans:

- `LangGraph`: the graph run, with the input messages and the final state
- `model`: the model node, with a `ChatOpenAI` generation that holds the prompt, the response and the token use
- `tools`: the tools node, with a `get_weather` span that holds the tool call's arguments and result

Langfuse also draws the graph of nodes in the [agent graph view](/docs/observability/features/agent-graphs).

![LangGraph trace in Langfuse](https://langfuse.com/images/cookbook/integration-langgraph/integration_langgraph_chatapp_trace.png)

## Users, sessions and tags [#users-sessions]

In Python, `propagate_attributes` sets the trace name, the [user ID](/docs/observability/features/users), the [session ID](/docs/observability/features/sessions) and tags on every span inside its block. In TypeScript, pass `userId`, `sessionId` and `tags` to the `CallbackHandler`. See the [LangChain integration](/integrations/frameworks/langchain) for all handler options.

## LangGraph Server [#langgraph-server]

The LangGraph Server invokes the graph itself, so add the handler to the compiled graph instead of the call:

```python
server_graph = graph_builder.compile().with_config({"callbacks": [langfuse_handler]})
```

## Troubleshooting [#troubleshooting]

If no trace appears:

- Check that `langfuse.auth_check()` passes and that the keys belong to the region in `LANGFUSE_BASE_URL`.
- Pass the handler in `callbacks` of every `invoke`, or add it with `with_config`.
- Call `langfuse.flush()` in Python, or `sdk.shutdown()` in TypeScript, before a short script exits.

See [Missing traces](/faq/all/missing-traces) for more causes.

## FAQ [#faq]

**How do I trace LangGraph without LangSmith?** Pass the Langfuse `CallbackHandler` in the `callbacks` of the invoke config.

**Does LangGraph need LangSmith for tracing?** No. LangSmith tracing stays off until its environment variable is set, and the Langfuse handler works without it.

**Does it work in TypeScript?** Yes. Use `CallbackHandler` from `@langfuse/langchain` and start OpenTelemetry with the Langfuse span processor.

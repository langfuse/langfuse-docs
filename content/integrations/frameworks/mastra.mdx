# Mastra agent observability with Langfuse

The Langfuse exporter in `@mastra/langfuse` sends each Mastra agent run, model call and tool call to Langfuse, and reads its keys from three environment variables. Mastra registers the exporter through `new Observability({ configs })`, passed to `new Mastra({ observability })`.

> **What is Mastra?** [Mastra](https://mastra.ai) is an open source TypeScript framework for building agents and workflows, with memory, tools and RAG.

> **What is Langfuse?** [Langfuse](/) is an open source LLM engineering platform for tracing, evaluating and debugging AI agents. Use [Langfuse Cloud](/cloud) or [self-host](/self-hosting) it.

> **How do they work together?** Mastra's observability system records a span for each agent run, model call, tool call and workflow step. The Langfuse exporter, a package maintained by Mastra, sends those spans to Langfuse.

<Callout type="info">
  Requires Node.js 22.13 or later. The code on this page ran with `@mastra/core` 1.85.0, `@mastra/observability` 1.24.2 and `@mastra/langfuse` 1.7.1, as of November 2026. `@mastra/langfuse` 1.7 needs `@mastra/core` 1.16 or later.

</Callout>

## Send traces to Langfuse [#setup]

Install Mastra, its observability package and the Langfuse exporter:

```bash
npm install @mastra/core @mastra/observability @mastra/langfuse @ai-sdk/openai zod
```

Add your [Langfuse API keys](/docs/observability/sdk/overview#client-setup) and your OpenAI key to `.env`:

```bash filename=".env"
LANGFUSE_SECRET_KEY="sk-lf-..."
LANGFUSE_PUBLIC_KEY="pk-lf-..."
LANGFUSE_BASE_URL="https://cloud.langfuse.com" # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com
OPENAI_API_KEY="sk-proj-..."
```

Define an agent:

```ts filename="src/mastra/agents/chef-agent.ts"
import { Agent } from "@mastra/core/agent";
import { openai } from "@ai-sdk/openai";

export const chefAgent = new Agent({
  name: "chef-agent",
  instructions:
    "You are Michel, a practical home chef. Help people cook with the ingredients they have.",
  model: openai("gpt-4.1-mini"),
});
```

Register the Langfuse exporter in an `Observability` instance. With the three variables set, the exporter takes no arguments.

```ts filename="src/mastra/index.ts"
import { Mastra } from "@mastra/core";
import { Observability } from "@mastra/observability";
import { LangfuseExporter } from "@mastra/langfuse";
import { chefAgent } from "./agents/chef-agent";

export const mastra = new Mastra({
  agents: { chefAgent },
  observability: new Observability({
    configs: {
      langfuse: {
        serviceName: "my-service",
        // Reads LANGFUSE_PUBLIC_KEY, LANGFUSE_SECRET_KEY and LANGFUSE_BASE_URL.
        exporters: [new LangfuseExporter()],
      },
    },
  }),
});
```

Run the agent with `npx tsx --env-file=.env src/run.ts`. In a short script, `mastra.shutdown()` flushes the exporter before the process exits. With `mastra dev`, which loads `.env` itself, chat with the agent in the playground instead.

```ts filename="src/run.ts"
import { mastra } from "./mastra";

const agent = mastra.getAgent("chefAgent");
const result = await agent.generate("What can I cook with chicken and lemon?");
console.log(result.text);

await mastra.shutdown(); // flushes the exporter before a short script exits
```

## Agent runs, model calls and tool calls in one trace [#trace]

Each agent or workflow run becomes one trace, named after the agent or workflow, with a span for each model call and tool call. Langfuse evaluators can filter on the trace name or on metadata such as `agentId`.

![Mastra trace in Langfuse](/images/docs/langfuse-mastra-trace.png)

## Sessions and metadata [#sessions]

Mastra maps `sessionId` in the span metadata to a Langfuse [session](/docs/observability/features/sessions), with the memory `threadId` as the fallback. Keys under `langfuse` in span metadata become trace metadata.

## Exporter options [#options]

Explicit options override the environment variables. `publicKey`, `secretKey` and `baseUrl` replace the three variables. See [Mastra's exporter reference](https://mastra.ai/reference/observability/tracing/exporters/langfuse) for all options.

| Option        | Effect                                                     |
| ------------- | ---------------------------------------------------------- |
| `realtime`    | `true` flushes after each event; the default sends batches |
| `environment` | Sets the Langfuse environment, for filtering               |
| `release`     | Sets the release, such as a git commit                     |

```ts
new LangfuseExporter({
  realtime: process.env.NODE_ENV === "development",
  environment: process.env.NODE_ENV,
  release: process.env.GIT_COMMIT,
});
```

## Link a Langfuse prompt [#prompts]

Mastra's `withLangfusePrompt` helper links a prompt from [Langfuse Prompt Management](/docs/prompt-management/overview) to the model calls of an agent, by prompt name and version. See the prompt linking section of [Mastra's Langfuse docs](https://mastra.ai/reference/observability/tracing/exporters/langfuse).

## Troubleshooting [#troubleshooting]

- **"Observability configuration error: Expected an Observability instance"**: `observability` was a plain `{ configs: ... }` object. Mastra then disables observability, the agent still answers, and no trace is sent. Wrap the config in `new Observability(...)` as above.
- **Storage warning**: Mastra falls back to in-memory storage, which is not durable. Configure a storage adapter in production; see the [Mastra docs](https://mastra.ai/docs).
- **No traces**: check that the keys belong to the region in `LANGFUSE_BASE_URL`, and that a short script calls `mastra.shutdown()`. See [Missing traces](/faq/all/missing-traces).

## FAQ [#faq]

**How do I add observability to a Mastra agent with Langfuse?** Install `@mastra/langfuse`, set the three variables and register `new LangfuseExporter()` in an `Observability` instance.

**Does Mastra send sessions to Langfuse?** Yes. `sessionId` maps to a Langfuse session, with `threadId` as the fallback.

**Does Langfuse show cost for Mastra runs?** The exporter sends the cost the provider reports. For other models, [model prices in Langfuse](/docs/observability/features/token-and-cost-tracking) cover the rest.

# Integrate Langfuse with Pydantic AI

This notebook provides a step-by-step guide on integrating **Langfuse** with **Pydantic AI** to achieve observability and debugging for your LLM applications.

> **About PydanticAI:** [PydanticAI](https://ai.pydantic.dev/) is a Python agent framework designed to simplify the development of production-grade generative AI applications. It brings the same type-safety, ergonomic API design, and developer experience found in FastAPI to the world of GenAI app development.

> **What is Langfuse?** [Langfuse](https://langfuse.com) is an open-source AI engineering platform. It offers tracing and monitoring capabilities for LLM applications. Langfuse helps developers debug, analyze, and optimize their AI systems by providing detailed insights and integrating with a wide array of tools and Pydantic AIs through native integrations, OpenTelemetry, and dedicated SDKs. Use [Langfuse Cloud](https://langfuse.com/cloud) (hosted by Langfuse, free tier, no infrastructure to run) or [self-host](https://langfuse.com/self-hosting) it.

### Step 2: Configure Langfuse SDK

Next, set up your Langfuse API keys. You can get these keys by signing up for a free [Langfuse Cloud](https://langfuse.com/cloud) account or by [self-hosting Langfuse](https://langfuse.com/self-hosting). These environment variables are essential for the Langfuse client to authenticate and send data to your Langfuse project.

```python
import os

# Get keys for your project from the project settings page: https://cloud.langfuse.com
os.environ.setdefault("LANGFUSE_PUBLIC_KEY", "pk-lf-...");
os.environ.setdefault("LANGFUSE_SECRET_KEY", "sk-lf-...");
os.environ.setdefault("LANGFUSE_BASE_URL", "https://cloud.langfuse.com"); # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com

# Your OpenAI key
os.environ.setdefault("OPENAI_API_KEY", "sk-proj-...");
```

With the environment variables set, we can now initialize the Langfuse client. `get_client()` initializes the Langfuse client using the credentials provided in the environment variables.

```python
from langfuse import get_client

langfuse = get_client()

# Verify connection
if langfuse.auth_check():
    print("Langfuse client is authenticated and ready!")
else:
    print("Authentication failed. Please check your credentials and host.")

```

### Step 3: Configure Pydantic AI instrumentation

This example uses the [Instrumentation capability](https://pydantic.dev/docs/ai/capabilities/instrumentation/), available in Pydantic AI 1.100.0 and later. It creates OpenTelemetry (OTel) spans for agent runs, model requests, and tool executions. The Langfuse SDK initialized above exports these spans to Langfuse.

Create the capability below, then attach it to your agent in the next step. The older `Agent(..., instrument=True)` argument is deprecated in recent Pydantic AI v1 releases and removed in v2; use `capabilities=[Instrumentation(...)]` instead. See the [Pydantic AI migration guide](https://pydantic.dev/docs/ai/overview/migration/).

```python
from pydantic_ai.capabilities import Instrumentation

instrumentation = Instrumentation()
```

### Step 4: Basic Pydantic AI application

Finally, run your Pydantic AI agent and generate trace data that will be sent to Langfuse. In the example below, the agent is executed with a dependency value (the winning square) and natural language input. The output from the tool function is then printed.

Attach the `Instrumentation` capability using the agent's `capabilities` argument. You do not need to call `Agent.instrument_all()` for an agent with this capability.

```python
from pydantic_ai import Agent, RunContext

roulette_agent = Agent(
    'openai-chat:gpt-4o',
    deps_type=int,
    system_prompt=(
        'Use the `roulette_wheel` function to see if the '
        'customer has won based on the number they provide.'
    ),
    capabilities=[instrumentation]
)

@roulette_agent.tool
async def roulette_wheel(ctx: RunContext[int], square: int) -> str:
    """check if the square is a winner"""
    return 'winner' if square == ctx.deps else 'loser'
```

```python
# Run the agent - using await since we're in a Jupyter notebook
success_number = 18
result = await roulette_agent.run('Put my money on square eighteen', deps=success_number)
print(result.output)

# Export buffered spans before viewing the trace or exiting the application
langfuse.flush()
```

## Instrumentation options

### Instrument all agents

To enable tracing across your application, call `Agent.instrument_all()` instead of attaching `Instrumentation` to each agent:

```python
from pydantic_ai import Agent

# Initialize the Langfuse client before enabling instrumentation.
Agent.instrument_all()
agent = Agent('openai-chat:gpt-4o')
```

`Agent.instrument_all()` remains supported. It sets the instrumentation options for agents that do not explicitly add an `Instrumentation` capability. Choose global instrumentation or configure each agent explicitly; the main example uses the per-agent approach.

### Missing traces with binary content

If text prompts produce traces but adding `BinaryContent` (for example, a PDF) causes traces to disappear, try excluding binary file data from telemetry:

```python
from pydantic_ai import Agent
from pydantic_ai.capabilities import Instrumentation
from pydantic_ai.models.instrumented import InstrumentationSettings

agent = Agent(
    'openai-chat:gpt-4o',
    capabilities=[
        Instrumentation(
            settings=InstrumentationSettings(include_binary_content=False)
        )
    ],
)
```

This workaround was [reported by the author of issue #13790](https://github.com/langfuse/langfuse/issues/13790#issuecomment-4517243741). It excludes binary file data from instrumentation events while keeping the media type in telemetry. The binary content is still sent to the model. See [InstrumentationSettings](https://pydantic.dev/docs/ai/api/models/instrumented/) for the available content-capture options.

For global instrumentation, pass the same settings to `Agent.instrument_all(InstrumentationSettings(include_binary_content=False))`.

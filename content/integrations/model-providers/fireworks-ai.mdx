# Observability for Fireworks AI with Langfuse

Fireworks AI runs fast inference and fine-tuning on open models with [OpenAI-compatible endpoints](https://docs.fireworks.ai/tools-sdks/openai-compatibility). Langfuse traces every Fireworks call (inputs, outputs, tool calls, token usage, and latency), and calculates cost when the model matches a [model definition](/docs/observability/features/token-and-cost-tracking#custom-model-definitions) with prices, so you can debug production behavior, score it with evals, and turn the traces that matter into datasets for experiments and fine-tuning. Fine-tuned models need a custom definition, and it applies only to traces sent after you save it.

> **What is Fireworks AI?** [Fireworks AI](https://fireworks.ai/) is a platform that provides API access to state-of-the-art open-source and proprietary AI models with OpenAI-compatible endpoints.

> **What is Langfuse?** [Langfuse](https://langfuse.com) is an open source AI engineering platform that helps teams trace API calls, monitor performance, and debug issues in their LLM applications. Use [Langfuse Cloud](https://langfuse.com/cloud) (hosted by Langfuse, free tier, no infrastructure to run) or [self-host](https://langfuse.com/self-hosting) it.

## Step 2: Set Up Environment Variables

```python
import os

# Get keys for your project from the project settings page
# https://cloud.langfuse.com

os.environ.setdefault("LANGFUSE_PUBLIC_KEY", "pk-lf-...");
os.environ.setdefault("LANGFUSE_SECRET_KEY", "sk-lf-...");
os.environ.setdefault("LANGFUSE_BASE_URL", "https://cloud.langfuse.com"); # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com

# Set your Fireworks API details
os.environ.setdefault("FIREWORKS_AI_API_BASE", "https://api.fireworks.ai/inference/v1");
os.environ.setdefault("FIREWORKS_AI_API_KEY", "fw_...");
```

## Step 3: Use Langfuse OpenAI Drop-in Replacement

```python
from langfuse.openai import openai

client = openai.OpenAI(
  api_key=os.environ.get("FIREWORKS_AI_API_KEY"),
  base_url=os.environ.get("FIREWORKS_AI_API_BASE")
)
```

## Step 4: Run an Example

```python
response = client.chat.completions.create(
  model="accounts/fireworks/models/deepseek-v4p1-flash",
  messages=[
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": "Why is open source important?"},
  ],
  name = "Fireworks-AI-Trace" # name of the trace
)
print(response.choices[0].message.content)
```

Find current model IDs in the [Fireworks model library](https://fireworks.ai/models). Fine-tuned models deployed on Fireworks use the same API, so their traces land in Langfuse the same way.

## Next: improve and fine-tune

Fine-tuning works best on deliberately selected examples. Langfuse helps you pick them:

1. **Score your traces** with [LLM-as-a-Judge](/docs/evaluation/evaluation-methods/llm-as-a-judge), [user feedback](/docs/observability/features/user-feedback) or [human annotations](/docs/evaluation/evaluation-methods/annotation-queues).
2. **Curate a dataset.** Filter by score and add the examples you want to learn from to a [Langfuse dataset](/docs/evaluation/experiments/datasets). Keep a holdout set for evaluation.
3. **Export it** via the [UI](/docs/api-and-data-platform/features/export-from-ui) or [SDK](/docs/api-and-data-platform/features/query-via-sdk), and convert to the [Fireworks fine-tuning format](https://docs.fireworks.ai/fine-tuning/fine-tuning-models): JSONL with one OpenAI-style `messages` array per line.
4. **Fine-tune on Fireworks,** then compare the tuned model with the base model on the holdout set using [Langfuse experiments](/docs/evaluation/experiments/experiments-via-sdk).

# Observability for Heabsy with Langfuse

This guide shows you how to integrate Heabsy with Langfuse. Heabsy serves open models through an OpenAI-compatible API, so you can use the Langfuse OpenAI drop-in replacement to trace all parts of your application.

> **What is Heabsy?** [Heabsy](https://heabsy.com) is a European inference API for open models with per-token pricing. API keys are issued on request via [heabsy.com/contacts](https://heabsy.com/contacts).

> **What is Langfuse?** [Langfuse](https://langfuse.com) is an open source AI engineering platform that helps teams trace API calls, monitor performance, and debug issues in their LLM applications. Use [Langfuse Cloud](https://langfuse.com/cloud) (hosted by Langfuse, free tier, no infrastructure to run) or [self-host](https://langfuse.com/self-hosting) it.

<Steps>
## Step 1: Install Dependencies

Make sure you have installed the necessary Python packages:

```python
%pip install openai langfuse
```

## Step 2: Set Up Environment Variables

```python
import os

# Get keys for your project from the project settings page
# https://cloud.langfuse.com

os.environ.setdefault("LANGFUSE_PUBLIC_KEY", "pk-...");
os.environ.setdefault("LANGFUSE_SECRET_KEY", "sk-...");
os.environ.setdefault("LANGFUSE_BASE_URL", "https://cloud.langfuse.com"); # 🇪🇺 EU region
# Other Langfuse data regions include 🇺🇸 US: https://us.cloud.langfuse.com, 🇯🇵 Japan: https://jp.cloud.langfuse.com and ⚕️ HIPAA: https://hipaa.cloud.langfuse.com


# Get your Heabsy API key (issued on request: https://heabsy.com/contacts)
os.environ.setdefault("HEABSY_API_KEY", "...");
```

## Step 3: Langfuse OpenAI drop-in Replacement

In this step we use the native [OpenAI drop-in replacement](https://langfuse.com/integrations/model-providers/openai-py) by importing `from langfuse.openai import openai`.

To start using Heabsy with OpenAI's client libraries, pass in your Heabsy API key to the `api_key` option, and set the `base_url` to `https://api.heabsy.com/v1`:

```python
# instead of import openai:
from langfuse.openai import openai

client = openai.OpenAI(
  api_key=os.environ.get("HEABSY_API_KEY"),
  base_url="https://api.heabsy.com/v1",
)
```

## Step 4: Run An Example

The following cell demonstrates how to call Heabsy's chat completions API using the traced OpenAI client. All API calls will be automatically traced by Langfuse.

```python
client = openai.OpenAI(
  api_key=os.environ.get("HEABSY_API_KEY"),
  base_url="https://api.heabsy.com/v1",
)

response = client.chat.completions.create(
  model="qwen38",
  messages=[
    {"role": "system", "content": "Act like you are a helpful assistant."},
    {"role": "user", "content": "What is a European alternative to a US inference API?"},
  ],
)

print(response.choices[0].message.content)

# In short-lived scripts, flush queued events before the process exits
from langfuse import get_client
get_client().flush()
```

Open [Langfuse](https://cloud.langfuse.com) to see the traced request, including model, tokens and latency.

Available model IDs and per-token prices are listed in the [Heabsy models catalog](https://heabsy.com/models).

<Callout type="info" emoji="ℹ️">
**Note:** The OpenAI drop-in replacement is fully compatible with the [Low-Level Langfuse Python SDKs](https://langfuse.com/docs/sdk/python/low-level-sdk) and [`@observe()` decorator](https://langfuse.com/docs/sdk/python/decorators) to trace all parts of your application.

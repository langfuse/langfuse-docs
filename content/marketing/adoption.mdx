# Langfuse is the most used open-source LLM engineering platform

Teams use [Langfuse](/) for [observability](/docs/observability/overview), [evaluation](/docs/evaluation/overview), and [prompt management](/docs/prompt-management/overview) of LLM applications and agents. This page collects the public metrics behind the claim. Most numbers below are live and refresh automatically.

## SDK downloads [#sdk-downloads]

Langfuse has the most downloaded SDKs among LLM observability and evaluation platforms on both PyPI and npm, apart from LangSmith, whose SDK ships with every LangChain install.

<Callout type="info">
  **\*Why LangSmith's numbers are skewed:** [`langchain-core`](https://pypi.org/project/langchain-core/) on PyPI and [`@langchain/core`](https://www.npmjs.com/package/@langchain/core) on npm both list `langsmith` as a required dependency. Every LangChain install downloads the LangSmith SDK, whether or not the team ever sends a trace, so the count measures LangChain's reach more than LangSmith adoption. Langfuse is not a LangChain dependency, so its downloads come from teams that install it on purpose. [Soba Labs' ranking of LLM eval and tracing tools](https://sobalabs.ai/blog/most-used-llm-eval-and-tracing-tools/) makes the same point.
</Callout>

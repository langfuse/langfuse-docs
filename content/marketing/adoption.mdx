# Langfuse is the most used open-source LLM engineering platform

Teams use [Langfuse](/) for [observability](/docs/observability/overview), [evaluation](/docs/evaluation/overview), and [prompt management](/docs/prompt-management/overview) of LLM applications and agents. This page collects the public metrics behind the claim. Most numbers below are live and refresh automatically.

<CredibilitySentence style="list" extended />

<Callout type="info">
  **How we compare.** We count each platform's main tracing SDK. LangSmith is
  not listed because `langsmith` is a required dependency of `langchain-core`
  and `@langchain/core`, so its download count reflects LangChain installs, not
  LangSmith usage. MLflow's count includes classic ML experiment tracking.
</Callout>

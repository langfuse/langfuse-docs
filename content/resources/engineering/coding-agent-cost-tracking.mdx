# Coding agent cost tracking: Claude Code, Codex, GitHub Copilot

Once a team uses more than one coding agent, cost lives in several places: an Anthropic org report, an OpenAI admin console, and GitHub billing. None of them shows the others, and none shows what a session did. This page explains how to bring all of them into one Langfuse project, so you can compare cost per developer, team, model, and session across agents.

<SignupCTA className="my-6" />

**TL;DR:** Route your coding agents through the [Langfuse AI Gateway](/docs/gateway/overview). It works with Claude Code, Codex, the GitHub Copilot CLI and app (bring-your-own-key models), OpenCode, and Pi, and records the cost of the actual API calls. Admins set it up once: developers get a gateway key and a base URL, and every call is attributed to them automatically. Add team and cost center as key metadata, and build one dashboard across agents.

## Why the gateway [#why-gateway]

- **Real cost, not an estimate.** The agent calls models with your organization's provider connection, so the cost Langfuse records is the cost of the calls you pay for. Use it for chargeback and budgets.
- **Set up once for the whole team.** Admins add the provider connection and the policy. Each developer only sets a base URL and their own key, and every call is attributed to them without per-machine configuration to maintain.
- **Complete coverage.** The gateway key is the only way to reach the model, so developers can't skip tracking by accident.
- **Central control.** Revoke one person's key, rotate provider keys without touching clients, and restrict which models can be called. See [gateway API keys](/resources/engineering/ai-gateway-api-keys) and [model allowlists](/resources/engineering/ai-model-allowlist).

## What drives coding agent cost [#cost-drivers]

Across agents, the same few patterns explain most of the spread between developers:

1. **Context size** comes first: agents that read many files or replay long histories send far more input tokens per call.
2. **Session length** compounds it, because many agents resend the conversation on every round.
3. **Model choice** changes the price per token by an order of magnitude between small and large models.
4. **Cache hits** reduce input cost. Generations record cached tokens separately, so you can see how much caching saves.
5. **Retries and loops** add cost without progress. Failed tool calls followed by the same model call are the signature.

Each of these is visible per session in Langfuse, which is why per-session data finds savings that monthly totals miss.

## One dashboard across agents [#dashboard]

With every agent in one project, the gateway [analytics page](/docs/gateway/features/analytics) and a [custom dashboard](/docs/metrics/features/custom-dashboards) answer the questions platform teams get asked:

| Chart                   | Configuration                                  |
| ----------------------- | ---------------------------------------------- |
| Cost per agent per week | Total cost, grouped by trace name              |
| Cost per developer      | Total cost, grouped by user                    |
| Cost per team           | Total cost, grouped on the `team` key metadata |
| Most expensive sessions | Sessions table sorted by cost                  |

Attach `team` and `cost_center` as [key metadata](/docs/gateway/features/api-keys#key-metadata) when a developer's key is created; clients can't change it. For cost attribution beyond coding agents, see [FinOps for AI](/resources/engineering/finops-for-ai).

## FAQ

<FaqDetails>

<Details id="which-coding-agent-is-cheapest">
<Summary>Which coding agent is cheapest?</Summary>

It depends on the plan, the model, and how your team works, so measure rather than compare list prices. Route every agent through the gateway into one Langfuse project and compare cost per session for similar tasks. For a direct comparison of two agents, see [Claude Code vs Codex](/resources/engineering/claude-code-vs-codex).

</Details>

<Details id="subscriptions">
<Summary>Does the gateway work with Claude or ChatGPT subscriptions?</Summary>

No. Through the gateway, agents call models with your organization's API credentials and are billed at API rates by the provider. Developers on a subscription plan log out of it before switching. See the per-agent guides for details.

</Details>

<Details id="can-developers-opt-out">
<Summary>Can developers opt out of tracking?</Summary>

Not through the gateway: the gateway key is the only way to reach the model, and a user key always records its owner. Remove direct provider keys so that traffic can't go around it.

</Details>

</FaqDetails>

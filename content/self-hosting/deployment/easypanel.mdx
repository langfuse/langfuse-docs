[Easypanel](https://easypanel.io) is a self-hosted Docker deployment platform. It maintains a one-click deployment template for Langfuse that provisions Postgres, ClickHouse, Redis, and MinIO for you.

## Deploy

Use the following button to deploy the Langfuse template on Easypanel:

[![Deploy on Easypanel](https://easypanel.io/img/deploy-on-easypanel-40.svg)](https://easypanel.io/templates/langfuse)

See the [architecture overview](/self-hosting#architecture) for details on each service the template creates.

## Features

Langfuse supports many configuration options and self-hosted features.
For more details, see the [configuration guide](/self-hosting/configuration).

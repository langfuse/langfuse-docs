# Railway

You can deploy Langfuse v4 on [Railway](https://railway.com/) via the prebuilt template.
The template runs the same services as the [Docker Compose setup](/self-hosting/deployment/docker-compose): Langfuse Web and Langfuse Worker (pinned to the same release), ClickHouse, Postgres and Redis, with a Railway Bucket as the S3-compatible blob storage.
See [architecture overview](/self-hosting#architecture) for more details.

On first start, the template uses [headless initialization](/self-hosting/administration/headless-initialization) to create your user, an organization, a project and its API keys, and it sets `AUTH_DISABLE_SIGNUP=true`, so the instance can't be claimed by someone else before you sign in. The deploy form asks for your email; the password and API keys are generated and shown in the service's variables.

<Callout type="info">

The stack needs about 3 to 4.5 GB of RAM in total (ClickHouse is the largest part), so it requires a Railway Hobby plan or higher.
Existing Langfuse v3 deployments on Railway can follow the [v3 to v4 upgrade guide](/self-hosting/upgrade/upgrade-guides/upgrade-v3-to-v4).

</Callout>

<Callout type="warning">
  After deployment, verify that PostgreSQL and ClickHouse use UTC. See the
  [timezone requirements and verification
  steps](/faq/all/self-hosting-timezone-errors).
</Callout>

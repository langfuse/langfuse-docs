# Select a region

Log in to Langfuse Cloud or sign up for a free account. Choose your region to access your projects, traces, prompts, and evaluations.

- **US**: [us.cloud.langfuse.com](https://us.cloud.langfuse.com), AWS us-west-2
- **US HIPAA**: [hipaa.cloud.langfuse.com](https://hipaa.cloud.langfuse.com), AWS us-west-2
- **Europe**: [cloud.langfuse.com](https://cloud.langfuse.com), AWS eu-west-1
- **Japan**: [jp.cloud.langfuse.com](https://jp.cloud.langfuse.com), AWS ap-northeast-1

[Learn more about data regions](/security/data-regions)

## Coding agents

Install the [Langfuse Agent Skill](/docs/api-and-data-platform/features/agent-skill) to let your coding agent set up tracing, manage prompts, and run evaluations. See [Langfuse for agents](/agents) for the CLI and MCP server.
